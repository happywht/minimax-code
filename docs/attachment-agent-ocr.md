# Agent 项目附件 OCR

Agent 可显式调用 `ocr_project_attachment`，对当前会话所属项目中已登记的 PNG、JPEG
或 PDF 附件执行本地 OCR。先通过 `list_project_attachments` 获取附件 ID 和 SHA-256；
调用时提供二者以及语言 `eng`、`chi_sim` 或 `eng+chi_sim`。PDF 必须提供 1 起始的
物理页码，图片不得提供页码。每次仅处理一张图片或一个 PDF 页，不会自动识别整个文档。

工具读取前核对项目绑定、附件类型及 SHA-256，原件读取过程还核验字节长度和哈希；
处理后再次检查会话项目与附件服务绑定。识别结果属于不可信来源数据，不是指令；`quality` 为
`unverified`，`truncated` 表示文字是否被截断。识别错误、遗漏、版式及业务含义均未核验，
空结果不代表页面没有内容。OCR 不改变附件原件或预览。

图片 OCR 需要本地安装 Pillow、tesserocr、Tesseract 和所选语言数据，PDF 还需要
PyMuPDF。缺少依赖或语言数据时返回明确错误；不会自动下载程序、模型或语言数据。
PDF 最多 200 页，图像与渲染页面最多 1200 万像素；原件最多 10 MiB。处理复用现有
附件解析 worker 的队列、超时、输出及资源限制。这些限制不是文件系统或网络沙箱。
工具遵守常规工具权限规则，也可在只读规划模式中调用。
