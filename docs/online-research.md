# 联网研究（普通聊天）

普通聊天可调用 `search_public_web` 搜索、`read_public_page` 读取公开页面。搜索需要配置支持 JSON 的公开 SearXNG 搜索端点或 Brave Search API；页面读取不依赖搜索配置。在“设置 → Providers → 联网研究”保存或清除地址，保存值立即生效。清除后回退环境变量；环境变量地址不在界面回显。也可在启动 agent 之前设置：

```powershell
$env:MINIMAX_CODE_SEARCH_URL = 'https://search.example.org/search'
uv run --project agent python -m minimax_code
```

上面的域名只是占位示例，须替换为用户选择的、允许 `format=json` 的真实公开 HTTPS SearXNG 端点。设置页面仅接受无凭据、无查询参数和片段、路径为 `/search` 的 HTTPS 端点（子路径部署可继续使用环境变量），SearXNG 地址不接受密钥；环境变量保留原有端点路径兼容性。配置文件保存在 agent 数据目录的 `research-settings.json`，不包含在现有数据包中，迁移数据时需另行重新设置；浏览器 mock 模式的设置只在当前页面进程内保留，不会访问搜索服务。未配置搜索时工具返回配置提示，不虚构搜索结果。聊天中可以直接要求“搜索某主题并引用来源”，或提供公开页面 URL 要求读取。搜索请求会将查询发送给所配置的服务；搜索摘要只来自搜索服务，不能视为已读取页面。页面结果包含最终 URL、标题、访问时间、正文摘录、截断标记和非可信内容提示，模型应对引用使用实际读到的页面，而不是把搜索摘要当作原文。

设置中的提供方也可选择 Brave Search API：提供自己的 API 密钥后保存至当前服务主机的系统密钥环，界面只显示是否检测到密钥，不验证有效性。清除密钥不会改变 SearXNG 地址；切换回 SearXNG 可继续使用已保存地址或环境变量。密钥不会放入 URL、设置文件或数据包；查询会发送给 Brave，使用可能产生费用，配额与收费以提供方账户为准。请求固定连接 `api.search.brave.com`，继续使用公网 DNS 和 TLS 检查，携带密钥的请求不跟随重定向。未配置密钥、非 JSON、HTTP 错误或网络不可用时返回错误；本地保存配置不代表服务可用或已测试。

项目研究来源面板也提供用户直接操作：点击“搜索网页”才向所选提供方发送查询，结果只显示未核验摘要；点击某条结果的“读取并保存”，或手动输入 HTTPS 网址后点击读取，才访问该页面。成功读取后以“用户手动读取网页”独立记录保存最终网址、实际时间和有界摘录，可刷新来源列表并用于报告；来源独立于该会话或 run 保存，删除项目会删除来源。网络拒绝规则仍有效，按钮代表单次手动操作，不修改 Agent 权限规则。切换项目、会话或服务后丢弃迟到的显示结果；响应中断时请先刷新列表确认，重试可能创建另一条来源。

两种工具仅在普通聊天注册。运行需网络权限：无规则时请求用户批准，无交互审批器则拒绝；`network` 或相应工具名的拒绝规则优先，明确允许规则可免重复询问。规划模式允许只读联网，但同样执行上述权限判断；受限执行上下文不注册这些宿主网络工具，且工具直接调用也会拒绝；不会绕过容器网络策略。

普通 Native 聊天中，成功读取的页面会以来源记录保存到当前项目的 run 日志；Agent 可通过 `list_research_sources` 按标题、网址或摘录搜索本项目的记录（按时间倒序，每次最多 20 条），在同一服务的后续任务使用 `page_source_id` 生成报告。可用 `offset` 浏览较早的匹配记录（上限 10000）；满页时返回的 `next_offset` 仅表示可能有下一页，记录变化可能影响跨页结果。DOCX、PDF 或双格式报告列出实际读取的最终 URL、标题、访问时间和最多 1000 字的摘录；无标题和截断会明确提示。原始记录保留最多 500 字标题和 8000 字摘录，并记载截断情况。模型仍需编写正文并自行对应编号，手工来源排在这些页面之前；每份报告最多 30 条来源。搜索摘要没有页面 ID，未绑定项目时不登记来源。此前仅保存在内存的旧来源 ID 不会自动补录，需重新读取。来源独立于所属 run 或会话保存，删除项目会删除来源；原 run ID 仅作历史线索，可能已不存在。升级时仅回填项目、会话、run 和服务身份一致且页面字段有效的记录，跳过归属不明或无效记录并在服务日志记录数量，原 run 记录不受影响。现有完整 SQLite 数据包包含它；服务身份随数据包克隆，不能证明克隆后的主机重新访问过页面。网页内容与报告事实均未自动核验。

Agent 可用 `get_research_source({page_source_id})` 读取已保存的完整有界摘录及原始截断标志，便于后续研究，不会重新访问网页。该操作检查当前会话、项目和服务绑定；来源内容仍是不可信输入，不能视为事实核验。

用户可在来源详情选中保存摘录中的任意片段（每次最多 4000 个字符），将原文连同标题、最终网址、访问时间、来源 ID 和所属运行追加到当前会话草稿。追加前重新读取并比较原文，同时核对项目、会话和服务；不会重新访问网页或自动发送。选中内容仍是有界摘录的一部分，不代表全文或已核验的事实。

只支持 UTF-8 的 HTML/纯文本页面及返回 UTF-8 JSON 的搜索服务，只访问 HTTPS 443，不使用系统代理，不处理其他编码、压缩响应、PDF、JavaScript 渲染或登录页面。每次响应最多读取 512 KiB、页面正文最多返回 8000 字符；超限明确标记。每次请求限定总时间及并发；逐跳解析并拒绝非公网地址，连接直接使用经验证的地址，TLS 校验原始域名；最多跟随三次跳转，并在每跳重新检查。若同一域名解析包含非公网地址则整体拒绝，已验证的多个公网地址会依次尝试。无法保证页面真实性、完整性或事实准确性；引用应由使用者核验。

本实现不能替代操作系统级隔离或网络防火墙；系统 DNS 解析由系统提供，阻塞解析线程可能在调用超时后继续至系统解析返回，最多保留四个并发工作槽。工具输出和外部页面均属于非可信输入。

搜索词命中保存摘录时，列表同时返回首次命中的上下文片段及其在保存摘录中从 0 起的字符位置（结束位置不含）；面板显示该片段，便于定位超过列表前 1000 字的内容。标题或网址命中而摘录未命中时没有该字段；空查询不返回命中片段。片段只来自已保存的有界摘录，不重新访问网页，也不证明全文完整或事实已核验。
