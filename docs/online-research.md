# 联网研究（普通聊天）

普通聊天可调用 `search_public_web` 搜索、`read_public_page` 读取公开页面。搜索需要配置支持 JSON 的公开 SearXNG 搜索端点；页面读取不依赖搜索配置。启动 agent 之前，在其进程环境设置：

```powershell
$env:MINIMAX_CODE_SEARCH_URL = 'https://search.example.org/search'
uv run --project agent python -m minimax_code
```

上面的域名只是占位示例，须替换为用户选择的、允许 `format=json` 的真实公开 HTTPS SearXNG 端点。端点不接受 URL 用户名、密码或查询参数；本功能不提供密钥配置。未配置搜索时工具返回配置提示，不虚构搜索结果。聊天中可以直接要求“搜索某主题并引用来源”，或提供公开页面 URL 要求读取。搜索请求会将查询发送给所配置的服务；搜索摘要只来自搜索服务，不能视为已读取页面。页面结果包含最终 URL、标题、访问时间、正文摘录、截断标记和非可信内容提示，模型应对引用使用实际读到的页面，而不是把搜索摘要当作原文。

两种工具仅在普通聊天注册。运行需网络权限：无规则时请求用户批准，无交互审批器则拒绝；`network` 或相应工具名的拒绝规则优先，明确允许规则可免重复询问。规划模式允许只读联网，但同样执行上述权限判断；受限执行上下文不注册这些宿主网络工具，且工具直接调用也会拒绝；不会绕过容器网络策略。

只支持 UTF-8 的 HTML/纯文本页面及返回 UTF-8 JSON 的搜索服务，只访问 HTTPS 443，不使用系统代理，不处理其他编码、压缩响应、PDF、JavaScript 渲染或登录页面。每次响应最多读取 512 KiB、页面正文最多返回 8000 字符；超限明确标记。每次请求限定总时间及并发；逐跳解析并拒绝非公网地址，连接直接使用经验证的地址，TLS 校验原始域名；最多跟随三次跳转，并在每跳重新检查。若同一域名解析包含非公网地址则整体拒绝，已验证的多个公网地址会依次尝试。无法保证页面真实性、完整性或事实准确性；引用应由使用者核验。

本实现不能替代操作系统级隔离或网络防火墙；系统 DNS 解析由系统提供，阻塞解析线程可能在调用超时后继续至系统解析返回，最多保留四个并发工作槽。工具输出和外部页面均属于非可信输入。
