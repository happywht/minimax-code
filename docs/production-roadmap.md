# MiniMax Code：个人生产工作台实施台账

采用用户于 2026-10-22 确认的 M0–M7 计划。评估起点 `78962fb`；保留 React SPA + FastAPI + JSON-RPC + SQLite。第一批范围固定为 **M0**，之后按阶段交付；本文件不把未来设计写成已经实现的能力。

## 产品与执行原则

- AI 编程 + 个人工作台；首批办公任务为研究、报告、表格。
- Windows 操作端，Linux 长驻执行端；质量优先，多模型可选，成本可见且可限制。
- NativeEngine 保留默认多模型能力；Codex App Server 为首个可选引擎，ClaudeEngine 后续扩展。
- 一个任务必须能看到主机/目录、引擎/模型、权限、预算、状态、等待原因、实际文件变化及验证证据。
- 任务“结束”与“验收通过”分别记录；模型自述完成不作为成功依据。
- 子 Agent 默认最多两个并行子任务，写任务各自隔离；不要为了形式而拆分。
- 按可独立验证的小变更交付，实现、测试、迁移与回退一起说明；不重写整个仓库，不为测试数量接入无产品用途模块。
- 当前由 Codex 直接实施；不自动委派 Claude CLI。

## 关键架构约束

### 统一运行

现有 RPC 保留兼容，逐步转交 RunService。聊天、继续、子 Agent、团队、定时和工作流经过统一入口；服务负责幂等、项目/模型/权限固定、预算、取消、事件、工具结果与验收。追加消息明确区分排队和中途补充。一个会话同时只运行一个写任务。

状态覆盖 queued、running、waiting_approval、waiting_input、budget_paused、interrupted、succeeded、failed、cancelled。状态与事件同事务提交，再推送 WS。关键事件可按游标补取，子 Agent UI 从持久记录恢复。

浏览器断线不取消任务。进程重启后遗留任务标中断，恢复入口解释完成与未完成步骤；只自动重试能证明幂等的步骤。结果不明的写操作必须待核对，不能盲目重放。

### 引擎与成本

会话创建时固定引擎，不运行中静默切换。切换引擎新建会话并附交接摘要；不假装内部状态能无损共享。公布实际能力，未支持的审批/预算操作在 UI 禁用。固定受支持的 Codex 协议版本，外部 session ID 持久保存。

模型名、窗口、价格来自配置/能力探测；未知 usage/价格显示未知。预算按父任务累计，包含子 Agent 和压缩；每次调用前检查。无人值守必须配置预算，耗尽暂停。实现单任务/每日预算及重复工具调用熔断。

### 隔离与主机

“工作区隔离”处理文件并发：Git worktree 或非 Git 独立输出目录。“受限执行环境”处理进程资源访问：容器或经验证的引擎沙盒。原生 Windows 标为本机受信执行。Linux 无人值守使用限定挂载、非特权用户、资源限制的容器，不挂 Docker socket；不可用就暂停。网络权限按运行配置，字符串黑名单不是隔离。

远程首版为 Windows 本地服务管理 SSH 配置引用和隧道，浏览器只访问本地服务；Linux 监听回环并由 systemd 用户服务长驻。每执行主机独立数据库及原始产物；对象按主机身份分区、切换主机清理视图状态。显式上传下载与校验，不自动同步凭据或整个目录。多主机配置、单活动视图；不做双向同步、运行中跨机迁移或分布式数据库。

定时任务固定项目、主机、引擎、模型、权限、预算和时区（默认 Asia/Shanghai）；不重叠，错过多个周期合并一次。缺少授权时等批准，不放宽权限。默认只通知完成、失败、需输入或实质变化。外部副作用授权不能从普通文件内容或模型建议推导。

### 交付物

主要界面入口为项目与任务、当前工作、交付物、自动化，复用现有设计体系。办公首批支持文本 PDF、DOCX、XLSX、CSV、TXT、图片，扫描件标明 OCR 状态；空解析不能当读完。

研究保存 URL、标题、访问时间及支持结论的摘录，区分事实、推断、不确定项。DOCX/PDF 必须渲染检查；表格检查公式、类型、汇总与引用。产物存在且可解析才能登记已交付，保存版本/来源/校验。三个工作流：专题研究→引用报告；资料提取→DOCX/PDF；表格清洗计算→XLSX/处理说明。

MCP 优先官方 Python SDK，保留现有配置和工具桥接；真实互操作覆盖 stdio、Streamable HTTP 与旧 SSE。后续改动前重新核对当时协议文档，不能将当前自建 SSE 视为现代协议已兼容。

## 接口与数据演进

| 对象/接口 | 必需信息 |
|---|---|
| RunRequest | 会话/项目/引擎/模型配置/输入/权限/预算/幂等键；主机由路由确定 |
| ExecutionContext | 固定工作区、Provider、模型、权限、预算，不读取可变全局选择 |
| RunEvent | 持久事件 ID、run ID、序号、类型、时间、内容 |
| run.* | 启动、状态、取消、恢复、事件补取；保留列表及步骤 |
| engine.* / host.* | 可用性/能力；主机配置、连接、健康、版本握手 |
| Artifact / attachment.* / artifact.* | 主机/项目/run/路径/MIME/大小/校验/来源/解析与验证状态；字节用认证 HTTP 传输 |

兼容 `agent.send_message`。任何变更同步契约、Python/TS 类型、typed IPC、mock 和文档。SQLite 只增加递增迁移，不重建用户数据。升级前备份；失败退回上一发行版及对应数据库备份，不做未经验证的逆向迁移。

## 最终完成定义

真实任务集固定 40 项：编程 20、研究办公 10、远程恢复 5、自动化 5；每正式候选版跑三轮，保存任务输入/基线/预算/输出与失败样本。按预设交付物评分，记录人工介入、耗时、用量。

- 总成功率 ≥90%，每类 ≥80%；安全/数据保全/幂等/取消关键回归 100%。
- 无未解决阻断、静默丢文件、跨项目写入或虚报成功；失败能定位 run、步骤、错误和产物。
- 远程断线后可查询，重连恢复；全新安装/升级/完整备份恢复实际演练通过。
- 连续 14 天 ≥30 个真实任务，记录人工接管原因，阻断修复后复验。
- 固定机器：冷启动 ≤8 秒；普通本地 RPC p95 ≤200ms；取消 1 秒内确认，进程通常本地 3 秒/远程 5 秒内停止。模型/网络时间单列。

首版不包括企业多租户、公开市场、移动 IM 全家桶、通用电脑控制、CAD/BIM、视频生产和运行中跨机迁移。名称暂留。

## M1 实施记录（2026-10-23，进行中）

- 显式绑定的项目目录、worktree 或会话失效时阻止执行；终端根据关联会话解析目录。
- 共享进程边界用于 exec、终端、验证、定时命令、Hooks、stdio MCP、内置检查工具及 rg。子进程使用环境白名单；超时覆盖输出管道排空，输出保留有上限。只读规划禁止任意命令和文件修改，文本搜索回退到 Python 读取。
- Windows 使用独立启动器先加入 kill-on-close Job 再启动命令，POSIX 使用独立进程组。它们用于生命周期管理，不是 OS 沙盒。依据 [Microsoft Job Objects 文档](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)；已在 Windows 真实进程中验证命令退出及启动器被杀后的子进程回收。
- 文件工具采用同目录临时文件、fsync、基线校验及原子替换。现有 overlay 子 Agent 禁止 shell，防止绕过合并直接写共享目录；独立 worktree 子 Agent 尚未接入，不能标为并发写生产就绪。
- HTTP/WS/预览增加认证、Host/Origin 校验，浏览器自动握手；只读规划选择进入 RPC 参数。认证与恢复的跨栈回归 23 项通过，握手子协议遗漏导致的首次 3 项失败及复验日志均保存在 `.verification/`。
