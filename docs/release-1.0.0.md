## 九条验收标准，逐条对账

1.0.0 不是版本号轮换，是对 [`docs/roadmap-to-1.0.0.md`](./roadmap-to-1.0.0.md) 开篇九条验收标准的逐条兑现：

1. **单进程生产模式可靠** ✅ — `pnpm start` 一条命令起完整产品（agent 静态托管 web/dist，同源免 CORS），production-mode e2e 4 用例覆盖 SPA / `/health` / `/rpc` 路由优先级 / 同源 WS / UI 聊天全链路。
2. **性能有基线** ✅ — 冷启动 / SQLite 索引 / 首屏产物 / 长会话渲染 / WS 重放五项基线（[`performance-baseline.md`](./performance-baseline.md)），bundle 预算硬断言进 CI，超限 exit 1。
3. **安全有边界** ✅ — CORS 白名单环境变量化、RPC 畸形请求四路拒绝（含 10MB body 上限）、`exec_*` 高危工具代码级出厂默认 ask、日志 handler 级密钥脱敏、secrets 走 OS keyring。
4. **数据可移植** ✅ — `data.export`（自描述 JSON 信封）/ `data.import`（校验 + 全事务替换式，all-or-nothing）/ `data.backup`（SQLite 在线快照），灾难恢复序列有端到端测试钉死。
5. **UI 文案统一** ✅ — `strings.ts` 中文单一来源 1100+ 行，全量英文清零，改文案只动一处。
6. **无障碍达标** ✅ — WAI-ARIA APG 对照的焦点陷阱、会话列表 roving tabindex、icon-only 按钮可访问名静态审计、设计 token WCAG AA 对比度 60 断言常驻 CI。
7. **文档完备** ✅ — README 重写（快速开始 / FAQ）、198 行用户手册、IPC 契约文档与 handler registry 双向守护测试（新增 handler 不写文档直接测试红）。
8. **可诊断** ✅ — `diag.export` 一键导出脱敏诊断包：无 keyring 值、无绝对用户路径，存储不可用时降级可用（故障时诊断工具更要用得上）。
9. **全量绿 + flaky 清零** ✅ — 三面套件全绿，e2e 三连跑（31.0 / 31.3 / 31.7 s）零失败。

## 快速开始

```bash
pnpm install
cd agent && uv sync && cd ..
pnpm start          # 构建前端 + 启动 agent，打开 http://127.0.0.1:8765
```

没有模型密钥也能完整体验：自动进入 mock 模式。开发模式与更多细节见 [README](../README.md)；面向最终用户的操作手册见 [`docs/user-guide.md`](./user-guide.md)。

## 从 0.x 升级

- **数据自动迁移**：启动时前向迁移自动执行（25 个迁移，显式事务，失败整体回滚），0.x 数据无缝带入 1.0.0。
- **配置无破坏性变更**：环境变量只增不改语义。
- **1.0.0-rc.1 起**：包元数据与 semver 的 prerelease 表达已桥接（`1.0.0rc1` ↔ `1.0.0-rc.1`），诊断包统一报告与文档一致的字面形态。
