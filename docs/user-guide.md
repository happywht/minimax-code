# MiniMax Code 用户手册

> 适用版本：v0.17.0 及以上。本手册面向**最终用户**——不需要读代码就能把产品用起来。
> 安装与部署见 [README](../README.md)，生产部署细节见 [deployment.md](./deployment.md)。

## 1. 五分钟上手

1. **启动**：项目根目录执行 `pnpm start`，浏览器打开 <http://127.0.0.1:8765>。
2. **配置密钥**：右上角打开「设置」→「Provider」标签页，添加服务商并粘贴 API 密钥。密钥存入系统钥匙串（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service），不落盘。
3. **开始对话**：左上角「新建任务」，在底部输入框输入问题，`Enter` 发送。

没有 API 密钥也能用：Agent 自动进入模拟模式，界面与工作流完整可用，回复为占位文本。配置密钥后即切换到真实模型。

## 2. 界面总览

```
+--------------------------------------------------------------+
| TopBar：命令面板 Ctrl+K · 预览 · Git 状态 · 通知 · 移动 · 主题 · 设置 |
+---------+--------------------------------------+---------------+
| Sidebar | ChatPanel（对话主区）                 | 检查器面板     |
| 项目分组 | MessageInput（输入框：@提及/附件/语音） | 11 个标签页    |
| 任务列表 | 或 设置页 / 技能库（覆盖层）           | 可折叠         |
+---------+--------------------------------------+---------------+
```

| 区域 | 职责 |
|------|------|
| 顶栏（TopBar） | 命令面板、预览切换、Git 状态、通知中心、明暗主题、设置入口 |
| 侧栏（Sidebar） | 项目分组的任务列表、新建项目/任务、搜索任务历史、Worktree 隔离任务、文本成果、项目附件、连接手机 |
| 对话主区 | 消息流（Markdown/代码高亮/Mermaid 图）、输入框、工具调用卡片 |
| 检查器面板 | 时间线、差异、进度、检查点、Agents、评审等运行时视图（见 §9） |

侧栏的项目分组可折叠（记住状态）；任务按更新时间排序。

## 3. 任务与项目

产品语言里一次对话就是一个「任务」（即会话）。

| 操作 | 做法 |
|------|------|
| 新建任务 | 侧栏「新建任务」按钮，或命令面板 `Ctrl+K` →「新建任务」 |
| 任务归入项目 | 侧栏新建项目后，通过任务选项菜单移动；项目决定侧栏分组 |
| 搜索历史 | 侧栏搜索框，按标题过滤任务历史 |
| 隔离实验 | 「创建隔离的 Worktree 任务」——在独立 Git worktree 中改动，不污染工作区 |
| 重命名 | 双击任务标题（或「任务选项」菜单） |

### 3.1 登记和查看文本成果

当前支持已有 **TXT、MD、CSV** 文件，须为 UTF-8 编码，单文件最大 **2 MiB**。

1. 选择一个项目，并在项目设置中填写明确的本机根目录。
2. 点击侧栏「文本成果」，输入项目相对路径，例如 `reports/result.md`，点击「登记新版本」。
3. 点击列表中的版本查看 SHA-256 和纯文本预览；Markdown 按文字显示，CSV 不执行公式。
4. 源文件修改后再次登记会创建新版本；选择旧版本并点击「下载原始字节」，取得该版本登记时的内容。

登记不会改写源文件，预览和下载使用保存的版本字节。列表当前显示最新 200 条，尚无
翻页入口。「可解析 / 未验证」不代表内容正确、研究完成或交付验收通过。PDF、Office、
图片附件解析及报告/表格质量验证尚未包含在这一入口。

删除项目后，保存的版本文件仍保留在数据目录中，但成果 API 要求项目仍存在，不能
继续通过原项目访问；删除前请下载需要单独保留的版本。完整保存这些版本还需备份
数据库及配套文件目录，见 §14。

### 3.2 上传和查看项目附件原件

1. 选择已有项目，点击侧栏「项目附件」。项目无需设置本机根目录。
2. 选择最大 **10 MiB** 的文件，点击「上传原件」。同名文件每次生成新版本，不覆盖旧原件。
3. 点击版本查看类型候选、解析状态和 SHA-256；TXT/CSV 成功后显示转义的纯文本预览，
   最多 **64 KiB / 2000 行**。选择版本后点击「下载附件原始字节」，取得上传时的全部字节。

TXT/CSV 要求严格 UTF-8，CSV 公式只作文字。空文本、预览截断、解析失败、类型不匹配分别显示；
安装可选 `attachments` 依赖后，DOCX 可预览正文段落与表格，PDF 可按物理页序预览已有文字
（最多200页）；两者仍受上述展示上限限制。PDF不保证版式或表格结构，空页标记表示未提取到文字，
不代表文件没有内容；未尝试 OCR。依赖或资源限制不可用时明确显示解析器不可用。
XLSX 可预览有界的存储单元格值，不重算公式；图片未尝试 OCR。所有状态都保留原件，不能当成已读完。
当前质量均为「未验证」，不代表研究、报告、表格或交付完成。附件不会自动塞入对话上下文；
在普通聊天中可让 Agent 列出当前项目附件并读取解析预览，截断的预览不能当作全文。
也可在附件面板填写标题与段落生成 DOCX，或让 Agent 根据资料生成 DOCX；生成文件登记为新附件，
可预览和下载，不覆盖项目原件。当前仅支持纯文本段落，不保证排版、来源事实或业务质量；
普通聊天中的生成操作需要写入授权。
此面板与输入框原有附件机制分别使用。列表显示最新200条；删除项目前下载需要独立保留的版本。
断开、超时或超限上传不产生可用记录；提交失败请刷新核对，不要把错误响应当作保存成功。
演示模式仅存在页内存，刷新清空。完整持久备份需保存数据库及两个配套 vault，见 §14.1。
安装与准确范围见 [DOCX](attachment-docx.md) 和 [PDF](attachment-pdf.md)；上传文件不会自动安装依赖。

## 4. 对话

### 4.1 输入

| 按键/入口 | 行为 |
|-----------|------|
| `Enter` | 发送消息 |
| `Shift Enter` | 输入框内换行 |
| `@` | 唤起子 Agent 提及选择器 |
| `Tab` | 确认提及选择器当前选中项 |
| 附件 | 输入框工具栏添加附件，随消息发送 |
| 语音 | 输入框麦克风按钮（浏览器语音识别） |

### 4.2 阅读回复

- 回复实时流式渲染，支持 Markdown、表格、代码高亮（代码块右上角一键复制）与 Mermaid 图。
- 助手调用工具时会插入**工具调用卡片**，展示参数与结果；「思考中」状态与轮次摘要在消息头部呈现。
- 消息操作菜单（悬浮）：复制、重试等。

### 4.3 工具授权

Agent 执行敏感工具（写文件、运行命令等）前会弹出**权限请求对话框**，展示工具名与参数：

- **允许** / **拒绝**：对本次调用放行或拒绝（`Enter` = 允许，`Esc` = 拒绝）；
- **总是允许**开关：批量放行同类请求，规则可在「设置 → 权限」管理/删除。

权限弹窗若涉及文件补丁，会同时预览改动内容（Patch 预览），确认后再落盘。

## 5. 模型与密钥

设置页分三个相关标签，分工如下：

| 标签 | 管什么 |
|------|--------|
| Provider | 服务商接入：地址、模型映射、密钥（多 Provider 并存） |
| 模型 | 当前会话用哪个模型；每个 Provider 的模型注册表（增删自定义模型 ID、上下文窗口） |
| API 密钥 | 旧版内置 MiniMax 密钥（兼容入口）；显示密钥状态：已存钥匙串 / 环境变量 / 未配置（模拟模式） |

切换模型：输入框上方的模型选择器，或「设置 → 模型 → 使用」。上下文窗口以 `XXk 上下文` 标注，支持工具调用的模型带「支持工具」标记。

`Ctrl+K` 打开命令面板，可直达：新建任务、预览面板、技能库、全部设置标签、任意历史任务（支持模糊搜索）。

## 7. 技能库

命令面板 `Ctrl+K` →「技能库」打开技能面板。技能 = 预封装的任务流程（SKILL.md 定义，可含工具绑定）。浏览已安装技能、查看说明、一键调用。技能规格见 [skills.md](./skills.md)。

## 8. 多 Agent 协作

### 8.1 子 Agent

对话中输入 `@` 提及子 Agent，把一段工作委托出去。子 Agent 的进度实时出现在：

- 检查器「子 Agents」标签：运行状态、产出；
- 「Agents」标签：Agent 定义管理（也可在「设置 → 子 Agent」配置）。

### 8.2 团队（Agent Teams）

「设置 → 团队」把多个 Agent 编成团队，分工协作跑复杂任务。团队运行时看检查器「团队运行」标签：每个成员的轮次、接力与汇总。「时间线」标签呈现整次运行的时序视图。

## 11. Git 集成、Code Review 与 Patch Studio

- **顶栏 Git 状态条**：当前分支、变更数；点击展开面板查看差异/日志（弹窗浏览，只读）。
- **Code Review**（检查器 → 评审）：对当前改动发起评审，逐文件查看意见。
- **Patch Studio**：Agent 产出的文件补丁以卡片呈现，可**逐文件应用/回退**、**全部应用/全部回退**、**保存快照**——改动落盘前先过目，不满意一键撤销。

## 12. 长期记忆

「设置 → 记忆」管理 Agent 的长期记忆条目：查看自动提取的记忆、手动增删。记忆在后续对话中被引用，让 Agent 记住你的偏好与项目背景。

## 13. MCP 服务器与插件

- **MCP 服务器**（设置 → MCP 服务器）：接入外部 Model Context Protocol 服务器，扩展 Agent 可用的工具集。
- **插件**（设置 → 插件）：启用/禁用内置功能模块。

## 14. 数据：导出、导入、备份

「设置 → 数据」三个动作，语义不同：

| 动作 | 格式 | 何时用 |
|------|------|--------|
| 导出数据 | 单个 JSON 文档（含 schema 版本，覆盖全部业务表） | 跨版本迁移、换机器 |
| 从 JSON 导入 | 替换式：文件中每张表在单事务内覆盖当前内容（要么全成，要么全不做） | 恢复导出文件 |
| 立即备份 | SQLite 文件级热快照（带 UTC 时间戳，Agent 不停机） | 同版本灾备 |

导入前会弹出确认（显示行数与 schema 版本）。**大规模导入前请至少保留一份备份**；旧版本会拒绝导入新 schema 的文件，而不是损坏自身。

文本成果的 JSON 导出只包含登记元数据，不包含文件内容；「立即备份」也只生成数据库
快照。保留或恢复文本成果时，须同时保存匹配的数据库与 Agent 数据目录中的
`text-artifact-vault` 文件夹。只导入 JSON 或只恢复 SQLite 文件不会补回缺失的原始
版本字节。

项目附件原件同样单独保存在 `attachment-vault`，JSON/SQLite-only 恢复也不能补回它们。

### 14.1 离线保存数据库、文本成果及附件原件

停止使用源数据目录的 Agent 后，可在已安装依赖的 `agent/` 目录执行：

```bash
uv run python -m minimax_code.bundle create --data-dir /absolute/stopped-data --output /absolute/backups/data-vault.zip
uv run python -m minimax_code.bundle verify --bundle /absolute/backups/data-vault.zip
uv run python -m minimax_code.bundle restore --bundle /absolute/backups/data-vault.zip --new-data-dir /absolute/fresh-data
```

将示例路径换成实际路径（Windows 也支持，空格须加引号）。父目录须已存在，输出包
位于源数据目录外，恢复目录必须全新且不存在。正在占用目录的服务、链接/损坏/超限
文件或不支持的格式会使操作失败；不会覆盖已有目标。该包保存一致 SQLite 快照和
全部已登记历史文本版本及附件原件，孤儿/待发布文件只计数、不收取。
当前新包为v3/Schema043；仍能校验/恢复旧v1/Schema041、v2/Schema042，不自动迁移，旧工具拒绝v3。
任一已登记原件缺失或损坏都会失败，不会默默跳过无法解析的附件。

这是 **data-only 副本，不能直接作为可运行实例启动**。数据库中的原主机路径、凭据、
定时任务及执行/安装身份保持原值，后续运营前须另行显式安全重新绑定。命令不启动
服务、调度、插件或模型。项目树、`.minimax`、未登记外部附件/配置/技能/插件文件、SSH、
钥匙串及容器/镜像不包含在内；包中的数据库本身仍可能含敏感字段。Windows 尚未验证
目录项断电持久性。这不替代完整应用备份或安装恢复演练；范围和限制见
[离线数据包说明](data-vault-bundle.md)。

本次附件与 v2 冻结候选在 Windows 相关 13 模块 258 项通过；真实 Linux 14 模块
271 项通过、1 项仅 Windows 路径用例跳过，其中附件/bundle/旧夹具 113 项全部执行。
前端相关 70 项、真实浏览器上传/预览/下载/刷新两项通过，类型/lint/构建通过；随后仅
统一演示模式的服务身份，相关 20 项重叠复验通过。测试不相加，也不代表完整应用运营
恢复或全部办公交付验收。精确范围、冻结来源及原始证据 hash 见上述说明。

## 15. 权限与审计

- **权限**（设置 → 权限）：工具授权规则清单——哪些工具免询问、哪些始终询问、哪些禁止。规则可增删改。
- **审计**（设置 → 审计）：敏感操作的历史记录，供回溯。

## 16. 移动配对

侧栏「连接手机」按钮打开配对对话框：展示配对令牌/二维码，在移动设备上完成配对后即可从手机查看任务进度；已配对设备列表支持解绑。数据仍全部保存在本机。

## 17. 外观与无障碍

- **主题**：顶栏切换深色/浅色，两套配色均满足 WCAG AA 对比度。
- **键盘**：全程可键盘操作——任务列表方向键漫游、对话框焦点陷阱、`Esc` 逐层关闭。
- **偏好**：尊重系统「减少动态效果」设置。

## 18. 异常状态横幅

| 横幅 | 含义 | 怎么办 |
|------|------|--------|
| 正在连接 Agent | 本地运行时启动中 | 稍候，自动完成 |
| 连接已断开 | Agent 进程不在了 | 自动重试中；重启 agent 后点「重试」 |
| 本地存储不可用 | 数据库降级，新会话不保存 | 重启 Agent 通常可恢复 |
| Provider 未就绪 | 密钥缺失或无效 | 去「设置 → Provider」补齐 |
| 崩溃恢复 | 上次会话异常退出 | 按提示恢复现场 |

## 项目附件的 DOCX 正文预览

服务可手动安装可选依赖 `cd agent && uv sync --extra attachments`，随后重启服务。
新上传DOCX只显示正文段落和表格，保留位置标签，最多64 KiB/2000行；
不含页眉页脚、修订、文本框、批注、脚注、图像OCR或版式质量检查。
“未提取到正文文本；未尝试OCR”不代表读完整个文档。面板显示算法版本、解析范围、
稳定原因与未验证状态。依赖缺失、格式异常、超时和资源超限仍可下载原始字节；
历史记录保留原解析版本，不自动重解析。演示模式不运行DOCX解析。
详见[DOCX有界解析](attachment-docx.md)。


本DOCX正文切片已有Windows私有staging后端163项、前端28项、真实浏览器2项通过，
以及最终Linux315项通过、1项仅Windows路径测试跳过的回执。最终补充文档证据及
一处不改变Python AST的末尾空白清理；
测试范围、两项测试修正与精确源码/回执hash见[本批验收证据](attachment-docx.md#本批验收证据)。
这些计数有重叠，不相加；质量状态仍为未验证，PDF/XLSX、OCR、完整办公交付和
独立Linux启动窗口故障仍未纳入本片验收。
