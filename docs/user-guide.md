# MiniMax Code 用户手册

> 适用版本：v0.17.0 及以上。本手册面向**最终用户**——不需要读代码就能把产品用起来。
> 安装与部署见 [README](../README.md)，生产部署细节见 [deployment.md](./deployment.md)。

## 1. 五分钟上手

1. **启动**：项目根目录执行 `pnpm start`，浏览器打开 <http://127.0.0.1:8765>。
2. **配置密钥**：右上角打开「设置」→「Provider」标签页，添加服务商并粘贴 API 密钥。密钥存入系统钥匙串（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service），不落盘。
3. **开始对话**：左上角「新建任务」，在底部输入框输入问题，`Enter` 发送。

没有 API 密钥也能用：Agent 自动进入模拟模式，界面与工作流完整可用，回复为占位文本。配置密钥后即切换到真实模型。

## 2. 界面总览

```
+--------------------------------------------------------------+
| TopBar：命令面板 Ctrl+K · 预览 · Git 状态 · 通知 · 移动 · 主题 · 设置 |
+---------+--------------------------------------+---------------+
| Sidebar | ChatPanel（对话主区）                 | 检查器面板     |
| 项目分组 | MessageInput（输入框：@提及/附件/语音） | 11 个标签页    |
| 任务列表 | 或 设置页 / 技能库（覆盖层）           | 可折叠         |
+---------+--------------------------------------+---------------+
```

| 区域 | 职责 |
|------|------|
| 顶栏（TopBar） | 命令面板、预览切换、Git 状态、通知中心、明暗主题、设置入口 |
| 侧栏（Sidebar） | 项目分组的任务列表、新建项目/任务、搜索任务历史、Worktree 隔离任务、连接手机 |
| 对话主区 | 消息流（Markdown/代码高亮/Mermaid 图）、输入框、工具调用卡片 |
| 检查器面板 | 时间线、差异、进度、检查点、Agents、评审等运行时视图（见 §9） |

侧栏的项目分组可折叠（记住状态）；任务按更新时间排序。

## 3. 任务与项目

产品语言里一次对话就是一个「任务」（即会话）。

| 操作 | 做法 |
|------|------|
| 新建任务 | 侧栏「新建任务」按钮，或命令面板 `Ctrl+K` →「新建任务」 |
| 任务归入项目 | 侧栏新建项目后，通过任务选项菜单移动；项目决定侧栏分组 |
| 搜索历史 | 侧栏搜索框，按标题过滤任务历史 |
| 隔离实验 | 「创建隔离的 Worktree 任务」——在独立 Git worktree 中改动，不污染工作区 |
| 重命名 | 双击任务标题（或「任务选项」菜单） |

## 4. 对话

### 4.1 输入

| 按键/入口 | 行为 |
|-----------|------|
| `Enter` | 发送消息 |
| `Shift Enter` | 输入框内换行 |
| `@` | 唤起子 Agent 提及选择器 |
| `Tab` | 确认提及选择器当前选中项 |
| 附件 | 输入框工具栏添加附件，随消息发送 |
| 语音 | 输入框麦克风按钮（浏览器语音识别） |

### 4.2 阅读回复

- 回复实时流式渲染，支持 Markdown、表格、代码高亮（代码块右上角一键复制）与 Mermaid 图。
- 助手调用工具时会插入**工具调用卡片**，展示参数与结果；「思考中」状态与轮次摘要在消息头部呈现。
- 消息操作菜单（悬浮）：复制、重试等。

### 4.3 工具授权

Agent 执行敏感工具（写文件、运行命令等）前会弹出**权限请求对话框**，展示工具名与参数：

- **允许** / **拒绝**：对本次调用放行或拒绝（`Enter` = 允许，`Esc` = 拒绝）；
- **总是允许**开关：批量放行同类请求，规则可在「设置 → 权限」管理/删除。

权限弹窗若涉及文件补丁，会同时预览改动内容（Patch 预览），确认后再落盘。

## 5. 模型与密钥

设置页分三个相关标签，分工如下：

| 标签 | 管什么 |
|------|--------|
| Provider | 服务商接入：地址、模型映射、密钥（多 Provider 并存） |
| 模型 | 当前会话用哪个模型；每个 Provider 的模型注册表（增删自定义模型 ID、上下文窗口） |
| API 密钥 | 旧版内置 MiniMax 密钥（兼容入口）；显示密钥状态：已存钥匙串 / 环境变量 / 未配置（模拟模式） |

切换模型：输入框上方的模型选择器，或「设置 → 模型 → 使用」。上下文窗口以 `XXk 上下文` 标注，支持工具调用的模型带「支持工具」标记。

## 6. 命令面板与快捷键

`Ctrl+K` 打开命令面板，可直达：新建任务、预览面板、技能库、全部设置标签、任意历史任务（支持模糊搜索）。

| 快捷键 | 作用 |
|--------|------|
| `?` | 打开快捷键面板 |
| `Esc` | 关闭面板/对话框 |
| `Ctrl+K` | 命令面板 |
| `Enter` / `Shift Enter` | 发送 / 换行 |
| `@` / `Tab` | 子 Agent 提及 / 确认选中 |
| `↑` `↓` `Home` `End` | 侧栏任务列表键盘导航（单焦点漫游） |

## 7. 技能库

命令面板 `Ctrl+K` →「技能库」打开技能面板。技能 = 预封装的任务流程（SKILL.md 定义，可含工具绑定）。浏览已安装技能、查看说明、一键调用。技能规格见 [skills.md](./skills.md)。

## 8. 多 Agent 协作

### 8.1 子 Agent

对话中输入 `@` 提及子 Agent，把一段工作委托出去。子 Agent 的进度实时出现在：

- 检查器「子 Agents」标签：运行状态、产出；
- 「Agents」标签：Agent 定义管理（也可在「设置 → 子 Agent」配置）。

### 8.2 团队（Agent Teams）

「设置 → 团队」把多个 Agent 编成团队，分工协作跑复杂任务。团队运行时看检查器「团队运行」标签：每个成员的轮次、接力与汇总。「时间线」标签呈现整次运行的时序视图。

## 9. 检查器面板（右侧）

| 标签 | 内容 |
|------|------|
| 时间线 | 当前任务的事件时序（消息/工具/里程碑） |
| 差异 | 工作区文件改动（配合 Git 状态） |
| 进度 | 任务步骤清单与完成度 |
| 检查点 | 快照列表——从某个检查点恢复上下文 |
| Agents | Agent 定义与管理 |
| 子 Agents | 本次任务的子 Agent 进度与结果 |
| 评审 | Code Review 工作流（见 §11） |
| 团队运行 | Agent 团队执行明细 |
| 终端 | 命令执行输出 |
| Runner | 运行器状态 |
| 代码库 | 代码库索引/检索视图 |

## 10. 自动化

| 功能 | 入口 | 说明 |
|------|------|------|
| 定时任务 | 设置 → 定时任务 | cron 表达式驱动，到点自动开任务执行提示词 |
| 工作流 | 设置 → 工作流 | 串联多步骤的固定流程 |
| Webhook | 设置 → Webhook | 事件发生时回调外部 URL |

## 11. Git 集成、Code Review 与 Patch Studio

- **顶栏 Git 状态条**：当前分支、变更数；点击展开面板查看差异/日志（弹窗浏览，只读）。
- **Code Review**（检查器 → 评审）：对当前改动发起评审，逐文件查看意见。
- **Patch Studio**：Agent 产出的文件补丁以卡片呈现，可**逐文件应用/回退**、**全部应用/全部回退**、**保存快照**——改动落盘前先过目，不满意一键撤销。

## 12. 长期记忆

「设置 → 记忆」管理 Agent 的长期记忆条目：查看自动提取的记忆、手动增删。记忆在后续对话中被引用，让 Agent 记住你的偏好与项目背景。

## 13. MCP 服务器与插件

- **MCP 服务器**（设置 → MCP 服务器）：接入外部 Model Context Protocol 服务器，扩展 Agent 可用的工具集。
- **插件**（设置 → 插件）：启用/禁用内置功能模块。

## 14. 数据：导出、导入、备份

「设置 → 数据」三个动作，语义不同：

| 动作 | 格式 | 何时用 |
|------|------|--------|
| 导出数据 | 单个 JSON 文档（含 schema 版本，覆盖全部业务表） | 跨版本迁移、换机器 |
| 从 JSON 导入 | 替换式：文件中每张表在单事务内覆盖当前内容（要么全成，要么全不做） | 恢复导出文件 |
| 立即备份 | SQLite 文件级热快照（带 UTC 时间戳，Agent 不停机） | 同版本灾备 |

导入前会弹出确认（显示行数与 schema 版本）。**大规模导入前请至少保留一份备份**；旧版本会拒绝导入新 schema 的文件，而不是损坏自身。

## 15. 权限与审计

- **权限**（设置 → 权限）：工具授权规则清单——哪些工具免询问、哪些始终询问、哪些禁止。规则可增删改。
- **审计**（设置 → 审计）：敏感操作的历史记录，供回溯。

## 16. 移动配对

侧栏「连接手机」按钮打开配对对话框：展示配对令牌/二维码，在移动设备上完成配对后即可从手机查看任务进度；已配对设备列表支持解绑。数据仍全部保存在本机。

## 17. 外观与无障碍

- **主题**：顶栏切换深色/浅色，两套配色均满足 WCAG AA 对比度。
- **键盘**：全程可键盘操作——任务列表方向键漫游、对话框焦点陷阱、`Esc` 逐层关闭。
- **偏好**：尊重系统「减少动态效果」设置。

## 18. 异常状态横幅

| 横幅 | 含义 | 怎么办 |
|------|------|--------|
| 正在连接 Agent | 本地运行时启动中 | 稍候，自动完成 |
| 连接已断开 | Agent 进程不在了 | 自动重试中；重启 agent 后点「重试」 |
| 本地存储不可用 | 数据库降级，新会话不保存 | 重启 Agent 通常可恢复 |
| Provider 未就绪 | 密钥缺失或无效 | 去「设置 → Provider」补齐 |
| 崩溃恢复 | 上次会话异常退出 | 按提示恢复现场 |
