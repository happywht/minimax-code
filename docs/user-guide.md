# MiniMax Code 用户手册

> 适用版本：v0.17.0 及以上。本手册面向**最终用户**——不需要读代码就能把产品用起来。
> 安装与部署见 [README](../README.md)，生产部署细节见 [deployment.md](./deployment.md)。

## 1. 五分钟上手

1. **启动**：项目根目录执行 `pnpm start`，浏览器打开 <http://127.0.0.1:8765>。
2. **配置密钥**：右上角打开「设置」→「Provider」标签页，添加服务商并粘贴 API 密钥。密钥存入系统钥匙串（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service），不落盘。
3. **开始对话**：左上角「新建任务」，在底部输入框输入问题，`Enter` 发送。

没有 API 密钥也能用：Agent 自动进入模拟模式，界面与工作流完整可用，回复为占位文本。配置密钥后即切换到真实模型。

## 2. 界面总览

```
+--------------------------------------------------------------+
| TopBar：命令面板 Ctrl+K · 预览 · Git 状态 · 通知 · 移动 · 主题 · 设置 |
+---------+--------------------------------------+---------------+
| Sidebar | ChatPanel（对话主区）                 | 检查器面板     |
| 项目分组 | MessageInput（输入框：@提及/附件/语音） | 11 个标签页    |
| 任务列表 | 或 设置页 / 技能库（覆盖层）           | 可折叠         |
+---------+--------------------------------------+---------------+
```

| 区域 | 职责 |
|------|------|
| 顶栏（TopBar） | 命令面板、预览切换、Git 状态、通知中心、明暗主题、设置入口 |
| 侧栏（Sidebar） | 项目分组的任务列表、新建项目/任务、搜索任务历史、Worktree 隔离任务、文本成果、项目附件、连接手机 |
| 对话主区 | 消息流（Markdown/代码高亮/Mermaid 图）、输入框、工具调用卡片 |
| 检查器面板 | 时间线、差异、进度、检查点、Agents、评审等运行时视图（见 §9） |

侧栏的项目分组可折叠（记住状态）；任务按更新时间排序。

## 3. 任务与项目

产品语言里一次对话就是一个「任务」（即会话）。

| 操作 | 做法 |
|------|------|
| 新建任务 | 侧栏「新建任务」按钮，或命令面板 `Ctrl+K` →「新建任务」 |
| 任务归入项目 | 侧栏新建项目后，通过任务选项菜单移动；项目决定侧栏分组 |
| 搜索历史 | 侧栏搜索框，按标题过滤任务历史 |
| 隔离实验 | 「创建隔离的 Worktree 任务」——在独立 Git worktree 中改动，不污染工作区 |
| 重命名 | 双击任务标题（或「任务选项」菜单） |

### 3.1 登记和查看文本成果

选择已登记的文本成果后，可点击「编辑文本副本」，在浏览器中修改并下载带 `-edited` 后缀的 UTF-8 副本。也可将编辑后的正文追加到当前会话聊天草稿，核对后自行发送；追加受聊天输入长度限制，过长时需精简。原项目文件和已登记快照不变；副本不会自动登记，CSV 格式与业务内容需自行核对。编辑内容只保存在当前页面，切换成果、项目、会话或服务、断线或关闭页面会丢失，请及时下载。此功能要求选定项目和会话，下载副本限 2 MiB。

当前支持已有 **TXT、MD、CSV** 文件，须为 UTF-8 编码，单文件最大 **2 MiB**。

1. 选择一个项目，并在项目设置中填写明确的本机根目录。
2. 点击侧栏「文本成果」，输入项目相对路径，例如 `reports/result.md`，点击「登记新版本」。
3. 点击列表中的版本查看 SHA-256 和纯文本预览；Markdown 按文字显示，CSV 不执行公式。
4. 源文件修改后再次登记会创建新版本；选择旧版本并点击「下载原始字节」，取得该版本登记时的内容。

登记不会改写源文件，预览和下载使用保存的版本字节。列表当前显示最新 200 条，尚无
翻页入口。「可解析 / 未验证」不代表内容正确、研究完成或交付验收通过。PDF、Office、
图片附件解析及报告/表格质量验证尚未包含在这一入口。

删除项目后，保存的版本文件仍保留在数据目录中，但成果 API 要求项目仍存在，不能
继续通过原项目访问；删除前请下载需要单独保留的版本。完整保存这些版本还需备份
数据库及配套文件目录，见 §14。

### 3.2 上传和查看项目附件原件

1. 选择已有项目，点击侧栏「项目附件」。项目无需设置本机根目录。

2. 选择最大 **10 MiB** 的文件，点击「上传原件」。同名文件每次生成新版本，不覆盖旧原件。
3. 点击版本查看类型候选、解析状态和 SHA-256；TXT/CSV 成功后显示转义的纯文本预览，
   最多 **64 KiB / 2000 行**。选择版本后点击「下载附件原始字节」，取得上传时的全部字节。

远端文件的文本预览也可确认保存为当前会话项目的附件。保存的是读取预览时校验的完整原始快照，而非屏幕显示的截断或过滤文本；文件可能包含凭据。它不会自动加入或发送聊天。连接变化或结果不明时，先在原服务的项目附件中按名称和 SHA-256 核对，再清除本标签页的待核对记录；该记录不跨标签页持久保存。此入口尚未运行验证。

TXT/CSV 要求严格 UTF-8，CSV 公式只作文字。空文本、预览截断、解析失败、类型不匹配分别显示；
安装可选 `attachments` 依赖后，DOCX 可预览正文段落与表格，PDF 可按物理页序预览已有文字
（最多200页）；两者仍受上述展示上限限制。PDF不保证版式或表格结构，空页标记表示未提取到文字，
不代表文件没有内容；未尝试 OCR。依赖或资源限制不可用时明确显示解析器不可用。
XLSX 可预览有界的存储单元格值，不重算公式；图片未尝试 OCR。所有状态都保留原件，不能当成已读完。
已解析的 XLSX 在项目附件、办公成果和任务关联成果中可按工作表查看坐标网格。表格使用后端已保存的有界解析记录，最多显示 A1:T100、1500 个已记录单元格及 64 KiB；未显示的格不代表空白，截断时也不能推断其他区域。公式只显示原文及未核验的缓存状态，不计算公式；数字保留存储原值，不推断日期、货币或百分比格式，ISO 日期保留原文。隐藏工作表会标识，不还原合并单元格、图表或布局。原始解析文本与原件下载仍可使用。

项目附件中类型匹配的 PNG、JPEG、GIF、WebP 可主动选择「查看图片原件」，并在适应面板与原始尺寸之间切换。预览限 5 MiB，获取时校验服务身份、字节大小和 SHA-256；切换会话、项目或连接时释放预览。动画可能自动播放，浏览器无法解码或文件超限时仍可下载原件。查看图片不代表内容或视觉质量已验收。

当前质量均为「未验证」，不代表研究、报告、表格或交付完成。附件不会自动塞入对话上下文；
在普通聊天中可让 Agent 列出当前项目附件并读取解析预览，截断的预览不能当作全文。
对于 PDF 和 DOCX，Agent 还可按 PDF 物理页或 Word 正文及表格段落继续读取原件；
该功能不做 OCR，也不保证提取 Word 页眉、脚注、修订或文本框。
也可以让 Agent 从上传的 UTF-8 CSV 选择列、转换类型并生成 XLSX；该功能读取完整原件，
支持现有汇总与图表，但有 1 MiB 和 1000 数据行的限制，不修改原文件。
对于简单 XLSX，可指定工作表后选择和转换列。常见日期转为 ISO 文本；百分比和货币保留
底层数值，不保留显示格式。公式、隐藏行列、合并单元格及含义不明确的格式需先在副本中整理。
限制详见 [办公成果](office-delivery.md)。
也可在附件面板或通过 Agent 根据资料生成 DOCX、PDF，或一次生成两种格式；生成文件登记为新附件，
可预览和下载，不覆盖项目原件。支持标题、章节、正文及简单表格，不保证排版、来源事实或业务质量；
报告的“章节可视编辑”支持增删、调整章节和段落顺序，并编辑纯文本表格；也可切换到 JSON 编辑。可复制章节或段落、表格内容，副本插在原项之后，保留文字、表格单元格及重复表头设置；复制后可独立编辑。若副本使章节、内容块、单元格或草稿大小超限，则不会更改草稿。引用编号和事实需自行核对。若 JSON 不能无损转换为可视编辑，原 JSON 保留并提示修正。DOCX 表格最多 100 行、20 列，PDF 另限 10 列、每表 1000 格；内容和版式不会因此自动核验。生成使用现有 DOCX/PDF 保存流程，创建新附件版本，不修改原件。

报告表单可搜索并选择当前项目已读取的研究来源，调整选择顺序；手工来源排在前面，正文编号需自行对应。生成时服务重新核对当前会话、项目、服务和所选记录，写入实际网址、访问时间及最多 1000 字摘录和截断标记。来源独立于所属任务和会话保存；删除项目后将无法使用。切换会话或服务会清空所选研究来源，但保留正在编辑的报告正文和手工来源。页面内容和事实不会自动核验。

报告可另行导出可编辑 TXT（最多 1 MiB）：保留正文、章节顺序和表格数据，表格每行用 JSON 字符串数组表达。导出前重新核对当前服务、项目、会话及所选来源，按附件 ID、哈希和范围复取原文，并读取研究来源的保存摘录；任一失效或草稿变化则不下载。文件由浏览器下载，不登记为项目附件，不还原 DOCX/PDF 排版；内容和引用仍需人工核对。

选中项目附件后，可查找完全同名的附件版本，逐页继续查找，并与当前版本并排查看有界解析预览；确认身份后可打开对照版本继续处理。同名版本只是同一项目按文件名登记的版本，并不证明内容或来源继承。预览可能为空或截断，不代表完整原件；比较不计算差异或核验质量，原件不改动。

报告的研究来源列表可勾选最多 10 条，一次将各条所选参考摘录及当前编号追加到正文或指定章节；未选段时取保存摘录开头最多 600 字。系统逐条重新读取并核对来源及范围，任何一条失效或目标内容超过限制时均不追加；正文中的空白会合并。追加后请逐处核对引用和事实；更改来源或顺序不会自动改写正文编号。

在项目附件中选择 PDF 或 DOCX，可准备其可读取文字并预览，随后替换普通正文或逐份追加到正文、指定章节；追加会附带原件名称、版本、ID 和哈希。对于 DOCX，也可选择替换正文并设置同名 DOCX 输出，编辑后生成新的附件版本。读取与确认均核对原件及当前作用域；原件不改动。DOCX 只读取正文及表格内段落，PDF 只读取物理页文字，不保留表格结构、版式、图片或未提取内容，不执行 OCR；空白会合并。原文标题、参考文献或引用编号不会自动解析，需人工核对，且受 100 次读取及报告长度限制。

附件列表还可批量选择最多 10 份 PDF、DOCX、UTF-8 TXT 或 CSV，将每份第一个可读取单元的开头最多 600 个 Unicode 字符及对应 `[资料N]` 引用一起加入报告正文或所选章节。批次先逐一按附件哈希和当前项目、会话及服务读取，任一首段为空、读取失败或草稿变化时不追加；报告生成时仍从原件复取引用范围。选择仅覆盖已加载附件，可先加载更多。首段不代表全文，正文中的空白会合并；不执行 OCR 或事实核验，事实与引用需人工核对。

对已加入报告的附件引用，还可勾选跨附件、跨物理页或段落的选段来准备资料初稿。预览展示原文、附件版本和哈希、物理页或段落位置、字符范围及当前单元截断状态；确认时再次复读并核对来源和草稿，然后将编号摘录与待填写的目的、资料不足和结论框架追加到现有正文或所选章节。不会自动发送、生成文件或覆盖原件；选段不代表全文，正文中空白合并，PDF 不自动 OCR，事实和引用需人工核对。

可逐条填写来源标题、网址和访问时间，报告会按顺序在文末编号列出；正文引用编号需自行对应，
系统不会自动核验来源。
项目附件及任务关联成果中，可主动选择「查看 PDF 原件」。系统先按服务身份、大小和 SHA-256 校验获取的原始字节，再交给浏览器的内置查看器；此入口限 5 MiB 且要求已有 PDF 文本解析结果，超限或解析失败仍可下载原件。切换会话、项目或服务时关闭预览并释放本地 URL。查看器不是隔离环境，文档中的外链或交互可能访问外部资源；浏览器不支持或显示空白时请下载查看。该视图不代表文档可信、内容正确或版式已验收。
普通 Native 聊天的 Agent 可查询本项目已读取的网页来源，并在后续任务通过来源 ID 将最终网址、标题、访问时间和有界摘录写入报告。来源保存在所属任务日志中，随任务或会话删除而删除；搜索摘要不会自动变成已读取网页。生成报告仍不代表引用关系或事实已核实。
用户也可从侧栏「文本成果 → 研究来源」搜索、查看已保存的项目来源，展开详情查看所属任务、原始摘录和截断标记，复制来源 ID 或手动打开网址。须先选择属于该项目的会话；切换服务或项目后请重新查询。

在交付物工作区的「研究来源」中，可按当前页的勾选顺序交接最多 10 条来源，或从详情交接单条来源到「附件与报告」。报告中需点击“核对并加入报告”：系统逐条重新读取来源并核对当前服务、项目和会话，全部成功后才按顺序加入；已有来源跳过，超出报告来源总数限制时不会加入。交接保存在当前页面内，刷新页面会丢失；可放弃交接。已有正文编号不会自动改写，页面内容和报告事实仍需自行核对。

交接多条来源后，也可选择“准备多来源报告初稿”，先预览每条来源的实际网址、访问时间和保存摘录；确认时重新核对来源及报告草稿，再将来源和带编号的摘录、待填写的研究范围和结论占位文字一起追加到普通正文或所选章节。已有报告内容保留，新增来源按当前顺序编号；不调用模型、不发送消息或自动生成文件。初稿不作事实判断，页面与摘录可能截断，引用、事实和结论均需自行核对。仅支持每次交接最多 10 条，引用总数及报告长度仍受现有限制。

搜索网页并逐个读取保存后，“本次已保存”列表可暂存最多 10 条，查看摘录并勾选，再按读取顺序直接交接到报告。列表满时可移出条目继续读取；移出不删除已保存来源。刷新来源列表、切换范围或连接变化会清空此临时列表，已保存记录仍可在项目来源中查找。搜索摘要本身不是来源；交接只使用成功读取并登记的页面，报告侧仍需核对并加入。

搜索结果也可勾选后点击“读取并保存所选页面”，按结果顺序逐页访问，最多使用本次列表剩余的 10 条容量；页内定位词适用于整个批次。每条成功后独立保存实际页面 URL、访问时间及摘录；可请求在当前读取返回后停止后续页面。遇到读取或回执错误时停止，已确认的结果保留，未确认页面可能已经保存，请先查询来源列表再决定是否重试。搜索摘要不会被登记为已读内容，网络限制及各页面读取范围仍适用，事实未经核验。
普通聊天中的生成操作需要写入授权。PDF 需要可用的中文 TrueType 字体；找不到字体时可按
[部署指南](deployment.md) 设置 `MINIMAX_CODE_PDF_FONT`。双格式请求部分失败或响应不明时，
先刷新附件并核对已保存的版本，再只重试缺失的格式。
此面板与输入框原有附件机制分别使用。列表显示最新200条；删除项目前下载需要独立保留的版本。
断开、超时或超限上传不产生可用记录；提交失败请刷新核对，不要把错误响应当作保存成功。
演示模式仅存在页内存，刷新清空。完整持久备份需保存数据库及两个配套 vault，见 §14.1。
安装与准确范围见 [DOCX](attachment-docx.md) 和 [PDF](attachment-pdf.md)；上传文件不会自动安装依赖。

## 4. 对话

普通聊天和只读规划可读取公开 HTTPS 网页，也可使用配置的搜索服务查找资料。
网页结果包含链接、标题、访问时间和有界摘录；搜索需要先设置 SearXNG 端点，
联网操作按权限规则确认。配置和支持范围见 [联网研究](online-research.md)。
输入框提供「专题研究」「资料成稿」「表格处理」模板；点击会将可编辑的任务说明
追加到草稿中，补充目标和要求后再发送，不会自动执行。

### 4.1 输入

| 按键/入口 | 行为 |
|-----------|------|
| `Enter` | 发送消息 |
| `Shift Enter` | 输入框内换行 |
| `@` | 唤起子 Agent 提及选择器 |

### 4.2 阅读回复

- 回复实时流式渲染，支持 Markdown、表格、代码高亮（代码块右上角一键复制）与 Mermaid 图。
- 助手调用工具时会插入**工具调用卡片**，展示参数与结果；「思考中」状态与轮次摘要在消息头部呈现。
- 消息操作菜单（悬浮）：复制、重试等。

### 4.3 工具授权

Agent 执行敏感工具（写文件、运行命令等）前会弹出**权限请求对话框**，展示工具名与参数：

- **允许** / **拒绝**：对本次调用放行或拒绝（`Enter` = 允许，`Esc` = 拒绝）；
- **总是允许**开关：批量放行同类请求，规则可在「设置 → 权限」管理/删除。

权限弹窗若涉及文件补丁，会同时预览改动内容（Patch 预览），确认后再落盘。

## 7. 技能库

命令面板 `Ctrl+K` →「技能库」打开技能面板。技能 = 预封装的任务流程（SKILL.md 定义，可含工具绑定）。浏览已安装技能、查看说明、一键调用。技能规格见 [skills.md](./skills.md)。

停用或卸载技能后，受管技能/Agent 运行及其子任务不会再启动该技能来源的后续 provider 工具；已经发出的调用可能继续。其他技能及内置工具不因此停用，已注入的说明文本不会从在途模型请求中撤回。

旧的 SkillRuntime 直接调用入口在等待同技能锁之后也会重新核对启用状态；如果它被配置为共享工具注册表，临时安装的工具及其副本在技能停用或安装结束后不能再次分发。默认应用的该入口未配置共享注册表，此限制不代表插件技能拥有统一的来源映射。

启用技能后可选择「运行」，在当前 Native 会话填写要求及可选 token 上限。提交只表示持久接单；运行受项目、工作区、权限和同会话队列约束。面板可刷新真实状态和结果或请求停止；结果未知、截断及验证证据需分别核对。接单响应丢失时，当前浏览器标签页会保留按服务与会话隔离的重试信息，可先刷新记录或重试同一请求；清除本地重试信息不会取消服务上的运行。

项目任务状态页的「查看结果」也可只读查看和下载该运行登记关联的文本版本，无需切换所属会话。

查看技能运行结果时，面板会显示该运行持久记录中可确认的关联附件，并复用预览和原件下载；也可查看登记关联到该运行的文本版本，或进入原会话时间线核对运行证据。文本登记关联不证明由该运行生成；成果内容未自动验证。项目文本列表最多返回最近 200 条，未登记、旧记录或登记失败的成果不会自动归入该运行，缺少关联不代表项目没有其他文件。

## 8. 多 Agent 协作

### 8.1 子 Agent

对话中输入 `@` 提及子 Agent，把一段工作委托出去。子 Agent 的进度实时出现在：

- 检查器「子 Agents」标签：运行状态、产出；
- 「Agents」标签：Agent 定义管理（也可在「设置 → 子 Agent」配置）。

### 8.2 团队（Agent Teams）

「设置 → 团队」把多个 Agent 编成团队，分工协作跑复杂任务。团队运行时看检查器「团队运行」标签：每个成员的轮次、接力与汇总。「时间线」标签呈现整次运行的时序视图。

运行团队前先选择会话；团队使用该会话的工作目录。可为团队设置共享 token 上限，留空使用服务默认值；成员调用也计入服务每日预算。运行结束后团队面板展示已知用量下界、预留和未知请求，估算额度不是严格费用上限。运行中的团队可在团队运行面板主动停止；系统会请求取消成员并等待已跟踪的后台子任务清理，然后将运行标为中断，实际写入结果需人工核对。服务重启后不能继续旧团队运行，也不会自动重放。独立工作副本不是操作系统沙箱。

团队成员派生的子 Agent 在开始前持久记录父运行与共享预算家族；其模型请求按子运行归属计入同一家族和每日账本。团队直接成员没有独立持久运行记录，仍归属于团队运行。旧记录不会追溯改写，未知用量仍须核对，不能按零处理。

团队入口属于执行模式；当前聊天选择规划模式时须先切换才能启动团队。成员执行工具时遵守当前权限规则，需要询问的操作由用户逐次授权；拒绝规则不会自动放宽。服务仍在线时断线重连可恢复有效的团队待授权请求。

团队接单前在同一 SQLite 只读事务中读取本轮团队模板和成员配置，并在内存中固定成员顺序、编排方式、提示词及成员模型选择；排队期间的普通配置编辑留待下次运行。启动前重新检查团队和成员仍存在且启用，并检查成员工具范围、技能列表和执行配置标识是否变化；不一致时停止本轮，请重新发起。快照只覆盖该次事务中已提交的团队和成员数据，不与后续接单或其他设置组成单一事务；运行开始后成员配置更改不会追溯应用，当前权限规则仍可收紧。技能内容和执行配置本身不在此快照中。团队接单时也固定默认模型客户端及推理强度；成员再次派生子 Agent 时继承该团队运行时，不因之后切换全局模型而改变默认客户端。模型选择不保证外部服务持续可用。权限、预算及工作副本约束继续适用。

团队与同会话的聊天及手动验证按接单顺序排队。排队期间可停止且不会开始团队执行；运行中停止后需核对未完成的操作。其他会话及共享项目目录仍可能同时发生变化。

会话队列中可逐项取消排队任务。确认时若该任务已开始，排队取消不会停止它；请刷新状态，再按需使用运行中的停止入口。取消请求未确认时应先查看任务记录，不会自动重试。

团队直接成员默认最多两个并行；启动时可填写 1–16 覆盖本次运行，留空使用服务设置（可由 `MINIMAX_CODE_TEAM_MAX_CONCURRENCY` 覆盖，显式非正数表示不限制）。接单后数值固定。普通后台子任务另有进程级限制，两者并非合计的全局并发上限。

每个真实执行的成员使用独立工作副本；结束后在团队运行卡或当前会话历史展开成员工作区，可审阅差异并明确收集无冲突的变化。父目录已变化或删除操作需要手动处理，依次收集不同成员时也会重新检查冲突。旧记录及中断时没有保存成员结果的运行不能从该入口收集；收集不代表验证通过。

收集和手动合并会核对审阅时的父目录身份，并在逐项写入前再次检查；目录被替换时停止，已写入的项目仍需查看收集记录。此检查不能排除外部进程在检查后立即替换目录或修改文件的竞态。

收集历史中，已确认复制且原文件有基线的项目可查看收集前备份，并经确认将内容恢复到父目录内不存在的新文件；原文件不会由此入口替换。备份须匹配原基线摘要且为不超过 16 KiB 的 UTF-8 文本；新增文件、结果未确认的文件及缺失或不匹配的备份需手动处理。删除仍须手动审阅处理，系统不会自动执行删除。

手动合并历史中的“查看合并前备份”支持把已核验的小型 UTF-8 备份恢复为父目录中的新文件：填写相对路径并明确确认，目标必须不存在、其父目录必须已存在。原文件不会被覆盖；若响应中断，请先检查目标文件再决定如何处理。

团队历史可按需读取已保存的成员开始、结束记录和有界结果；截断会标明。服务重启或运行停止后，没有结束记录的成员结果视为未知，不自动重放。已中断团队仅在成员完成、工作区完成、受管任务收束记录存在且服务内无活动运行时，可审阅并明确确认收集该成员；旧中断或证据不足的记录仍不能收集。受管任务收束不证明外逸进程已停止，确认前须自行核对相关进程；旧记录可能没有成员步骤。

收集后可选择「审阅并运行项目验证」，先确认项目当前配置的命令和目录；命令可能修改文件或访问网络。验证作为单独运行记录，可请求停止并刷新真实输出和退出状态；超时、停止或结果缺失时为未知。结果仅反映该次命令，不能代替验收；服务或项目绑定变化后需重新审阅。

刷新验证结果后，可选择将保存的验证记录加入当前会话草稿；追加前重新核对服务、项目、会话、子任务和验证运行及内容。摘录最多 4500 字符，超出会标明；内容可能含敏感信息，需审阅后手动发送。此操作不会重新执行验证，也不证明当前文件没有变化。

## 9. 检查器面板（右侧）

已有项目可通过侧栏项目菜单的「项目验证设置」编辑根目录与验证命令。Native 可写任务正常完成后，会在其工作区执行接单时保存的命令；Codex 可写任务正常完成后先逐次请求主机执行授权，获准且会话、项目和工作区仍匹配时执行。右侧时间线对应任务的「查看验证命令与输出」展示已记录的命令、退出码、超时、错误和截断后的输出。拒绝或超时授权、规划模式、未配置命令及未正常完成的任务不会得到验证通过结论。命令执行的是宿主 shell，可访问主机文件和网络，不受 Codex 工作区沙箱保护，须由用户自行信任。更新设置只影响之后接单的任务，已绑定独立工作区的会话仍使用自己的目录。

只读规划正常结束后，在最终回复中可选择「准备执行此计划」。计划会追加到当前会话草稿并切换为执行模式；已有草稿会保留。请检查计划、服务、会话、工作区和下一任务预算，按需修改后再发送。发送会使用会话绑定的引擎及其正常权限流程；准备操作本身不会运行任务。截断或未完成的规划不能通过此入口提交，超出输入上限时需先精简草稿或手动整理计划。

较早的已完成规划也可在同会话时间线选择「读取历史计划并编辑」。界面按需读取持久回执及可用的结构化计划；编辑后明确加入草稿时重新核对服务、项目、会话和运行记录游标，不自动发送。缺少完整记录或计划过长时需回原会话手动整理；这是模型计划，不是执行或验收证据。

新 Native 任务的报告和表格生成工具返回已确认保存的成果后，时间线可直接打开关联附件的有界纯文本预览或下载原件。预览与下载会复核当前会话、项目、服务身份及附件校验值；幂等请求可能返回以前保存的成果，关联只表明本任务的工具返回了它。业务内容和版式仍未验证。旧任务、手工生成的成果、未确认保存的结果或未成功记录关联的附件不会自动归入任务，可在项目附件或办公成果中查找。

时间线中可用「查看工作区当前差异」读取该任务绑定目录的 Git 状态：分别查看已暂存、未暂存的已跟踪文件差异和未跟踪文件名。这里展示查询时的共享工作区，可能包含用户或其他任务的修改，也可能在任务结束后继续变化；它不是任务独有的变更记录，不包括已提交的变更或未跟踪文件的内容。各部分分别读取，工作区正在变化时结果不保证是同一时刻的快照。 已跟踪文件差异可以跨已暂存和未暂存区域选择最多 10 项，填写意见后一次追加到当前聊天草稿。追加前逐项重新核对差异及工作区身份；每项最多附 4000 字符、总计最多 20000 字符，未完整加入时会标明。此操作不自动发送、不执行验证，差异可能包含用户同期修改。此功能尚未运行验证。 选择未跟踪文件后可只读预览不超过 64 KiB 的 UTF-8 文本，并填写审阅意见追加到当前聊天草稿。追加前会重新读取并比较内容和工作区归属；草稿最多包含前 12000 字符，标明截断，不会自动发送或执行验证。文件内容可能含敏感信息，分享前应检查；预览后的后续变化仍可能发生。此功能尚未运行验证。旧任务缺少项目或工作区绑定、绑定发生变化，或者目录不是 Git 仓库时，不能使用此视图。

发送前可勾选「采集任务前后文件变化」；默认关闭。运行实际开始前与结束后分别读取绑定目录中 Git 已跟踪及未忽略的未跟踪普通文件，时间线的「查看任务前后文件变化」列出新增、修改和删除的路径，不保存文件内容。每次最多 1000 个文件、16 MiB 内容，Git 列举和文件读取各限 2 秒；超限、不可读取、链接或绑定变化时结果不可用，任务仍继续运行。Git 忽略文件、`.git` 和 `.minimax` 不纳入；独立工作区只检查自身。采样不是原子快照，也可能包含用户和其他任务同期修改，不能归因给 Agent；服务重启无法补采之前的基线，旧任务不会自动获得此记录。

| 标签 | 内容 |
|------|------|
| 时间线 | 当前任务的事件时序（消息/工具/里程碑） |
| 差异 | 工作区文件改动（配合 Git 状态） |
| 进度 | 任务步骤清单与完成度 |
| 检查点 | 快照列表——从某个检查点恢复上下文 |
| Agents | Agent 定义与管理 |
| 子 Agents | 本次任务的子 Agent 进度与结果 |
| 评审 | Code Review 工作流（见 §11） |
| 团队运行 | Agent 团队执行明细 |
| 终端 | 命令执行输出 |
| Runner | 运行器状态 |
| 代码库 | 代码库索引/检索视图 |

检查点捕获的 Git 补丁可按文件展开，并填写审阅意见追加至当前项目会话草稿；追加前重新读取检查点和补丁并核对服务及会话。草稿最多包含所选补丁前 12000 字符，超出时标明；请检查是否适合分享。捕获补丁不是当前工作区差异或撤销预览，不会自动应用、发送或运行验证；当前文件可能已变化。旧检查点仍需先核实原目录。该功能尚未运行验证。

在代码库搜索结果中选择「读取当前源码并加入草稿」，可把该结果的当前工作区文件行范围追加到当前会话草稿，审阅后手动发送；搜索片段仍来自可能过期的索引，文件变化后行号可能指向不同内容。此功能要求 `read_file` 的明确允许规则，询问或拒绝规则不会自动授权；限 UTF-8 普通文件、64 KiB、100 行和 6000 字符，并拒绝链接及敏感路径。草稿内容可能在读取后过期，也会按聊天草稿的存储方式保留。

顶部 Git 查看器可切换未暂存、已暂存和最近提交相对其父提交的差异。有当前 Native 会话时差异取该会话绑定的工作区，目录失效或读取期间被替换会报错；其他情况查看项目目录，界面会标明。日志标签仍按项目目录查看。结果是读取时快照，不归因于某个任务；未暂存视图不包含未跟踪文件，查看不会修改或提交文件。目录身份检查不能排除外部进程在检查后立即替换的竞态。

清理会话工作树前会检查已接收、排队或运行中的受管任务；使用该目录的任务尚未结束时不能清理。清理失败时会话及其绑定会保留，以便核对目录和运行状态；清理仍不能检测所有外部进程或其他服务对目录的使用。

设置中的 Native 工作树列表可选择「审阅未提交差异」，按所选会话的工作树读取已跟踪文件差异和未跟踪文件列表，并可选择未跟踪文件读取当前文本前 100 行；读取前后核对服务与会话绑定。文本读取需要 `read_file` 明确允许，并限制 UTF-8、64 KiB、6000 字符，拒绝链接、敏感及排除路径；空文件或不可安全读取的文件会提示。视图不包含已提交变更，各次读取不是原子快照，因此不能作为完整合并预览或验证结论；审阅不会添加、提交或合并。

任务前后文件变化列表中，可选择记录路径查看当前源码前 100 行。读取前后会核对任务的服务、会话、项目及工作区绑定，使用相同的文件读取权限和大小限制。文件已删除、范围过大或不可安全读取时会提示；预览只反映当前状态，不证明文件由该任务修改，也不执行修改或验证。

连接恢复后，当前会话会刷新运行时间线；任务仍在运行时，聊天会补入该任务最近已保存且本页缺失的工具结果，不替换正在流式显示的文本或本地输入。任务结束后再恢复已保存的聊天记录。工具结果只在服务端写入后可恢复；读取范围为最近 500 条消息及时间线最近 20 次运行，聊天已达到显示上限时不会为补取结果丢弃当前内容。连接或读取失败时保留现有视图，可在重新连接后重试。

从定时任务打开的指定运行时间线不受最近 20 次运行限制。断线后该视图停止使用旧快照；没有未提交恢复编辑时，在原服务地址、项目和会话重连会自动重新读取目标运行。有未提交恢复编辑时需手动重新读取；读取会再次核对服务身份、工作区和定时发生记录。范围变化或核对失败时显示错误，需返回原任务重新选择；读取不会重放工具或任务。

达到迭代上限而尚未完成的 Native 运行，也可在时间线或项目历史中核对后接续：先检查记录、工作区和可能的外部副作用，再填写可选交接并确认。接续创建关联的新运行，沿用原模型、工作区、权限快照和累计预算，不自动重放工具步骤；它不是精确断点恢复。

接续普通任务时可选择明确提高累计 token 上限；默认沿用原上限，已用额度、子任务用量和未知责任不会清零，每日额度仍生效。先查看共享预算账本，未确认责任须核对后才能继续。定时运行达到迭代上限后的接续仍保留原预算。

在「项目与任务 → 任务状态与结果」查看预算暂停运行时，可直接读取共享家族用量、预留及核定责任、当日账本和不明请求，并刷新或翻页。读取会核对服务、运行和所属项目会话；该视图不核定责任。需要处理时切换到所属会话，在预算账本核对责任，再使用结果下方的受控恢复入口；恢复需明确审阅和确认，不会自动重跑，原权限快照和累计预算规则仍然生效。账本没有记录或用量不完整时，不把未知责任当作零。

任务预算账本中的当日未知请求可继续翻页，查看其他责任任务并进入其会话核对。翻页期间账本可能变化，可刷新从头查看；查看不会核定责任或放行新的模型请求。

同一 Agent 服务进程仍在等待时，重连会重新显示当前会话尚未回答的 Native 提问及尚未决定的 Native 或 Codex 工具权限审批。恢复只显示审批，不自动授权；已经回答、决定、取消或到期的请求不能再次提交。计时仅为提示，服务端在收到回答或决定时再次核对是否有效。服务进程或 Codex 进程退出会结束相应内存等待，不能借此继续旧请求。

同一运行的多个子 Agent 同时提问时，定时任务通知可打开其中对应的有效问题；切换问题时保留未提交的本地草稿。通知只定位原服务、原运行和原会话的当前等待，不会回答问题。

Codex 文件修改审批会展示已收到的文件差异和额外写入范围；预览有大小限制，缺少详情或被截断时会提示。请结合工作区核对后决定是否授权。

Codex 的 MCP 工具调用会显示在任务时间线，展开可查看服务、工具、参数和结果的有界预览；引擎报告的失败及未确认的结束状态会保留。内容可能截断或缺失，完成状态不等于独立验证结果。MCP 调用由 Codex 和对应服务管理，本界面不因此授予额外权限。

在 Codex 任务时间线查看历史输入图片时，可逐张选择「加入当前草稿」并确认。系统重新核对原图片和服务、项目、会话，再检查草稿图片总数及大小；加入不会自动发送，也不改变预算或审批。草稿图片只保存在当前页面内存，切换会话、项目或服务及刷新页面后会清除，可从原任务再次选择；原任务图片不受影响。

核对 Codex 中断任务时，可按需读取原任务文字，编辑摘录后加入恢复交接；这有助于说明可能尚未到达引擎的输入。请核对敏感内容、已发生的操作与摘录是否完整。原文字预览有长度限制，图片只显示数量，不会自动重发。加入交接本身不会发送；仍须审阅、确认并遵守恢复预算与审批。

Codex 任务概览展示引擎已报告的输入、输出和合计 token 及用量确定性；运行中收到新的用量事件后会更新。未知不按零计算，恢复区间可能包含未观察期间的用量，异常水位也不能视为完整用量；这些数字不是费用或严格预算保证，仍可查看共享预算账本。

已完成的 Codex 任务可在时间线选择「复用原任务文字」，编辑后追加到同一会话的草稿；加入前会重新核对原输入和线程。只显示前 4000 字，原任务图片不自动加入，可通过图片回看入口另行选择。该操作不会发送或改变预算；请检查敏感内容、补充新目标后手动发送。缺少可核对的原输入或线程绑定时无法使用。

Codex 报告网页搜索事件结束后，任务时间线可展开查看查询和动作的有界预览；事件结束不说明搜索成功或来源已核实，搜索结果本身不在此处保存。没有收到结束事件时不会显示这条记录。网页访问仍由 Codex 的配置控制。

Codex 会话可通过输入区的文件按钮或拖放插入文本文件：内容展开为可编辑的草稿文本，发送的是文字，不是文件附件。文件内容超过 32000 字符会截断，整个草稿仍受 8000 字符上限约束；请发送前检查并精简。移除文件标签不会删除草稿中已插入的内容。也可通过图片按钮选择最多 5 张 PNG、JPEG、GIF 或 WebP 图片，总计不超过 4 MiB；模型或提供方是否支持图片由 Codex 决定，失败会显示为任务失败。图片数据随任务请求保存在本地数据库、可能包含在数据导出中，也会发送给 Codex；消息历史显示图片数量，任务时间线的「查看任务输入图片」可逐张回看原任务的已保存图片；查看本身不会加入草稿或发送。旧记录、纯文本任务或绑定发生变化时无法读取。恢复任务不会自动重发原图片。`@` 和 `#` 作为普通文字，不触发 Native 的提及功能。切换会话、项目或服务时，正在读取的文件不会插入新上下文。

服务进程仍运行时，当前会话的 Native 和 Codex 流式文字会在重连后从内存快照补齐；增量按消息段序号去重，缺口会触发再次读取。此快照最多 2 MiB UTF-8、2 万个增量或 256 个消息段，超限后仍显示后续实时文字，但无法补齐之后漏收的内容，界面会提示任务结束后查看已保存记录。它不是持久日志：服务重启后未保存的 Native 中途输出无法由该快照恢复；任务最终保存的记录仍为准。

输入区的「排队一个新任务」接收纯文本，作为当前会话的独立任务排在已有任务之后；没有前序任务时立即运行，不会插入正在执行的轮次。提交后以时间线的任务状态为准，尚未开始的已接收内容可以展开查看（最多显示 8000 字）。同一会话有上限，停止会话也会取消排队任务。Codex 若前序任务结果不确定，后续任务会停止并要求先核对；此入口不会向正在执行的轮次插入内容。

项目任务状态的「查看结果」同时显示读取时的运行快照、已保存的验证命令及输出、失败步骤和关联成果。失败步骤最多显示前 25 项，每项错误或摘要最多显示 2000 字符；可打开所属会话查看完整记录。运行状态、验证命令的结果和模型文本各自独立，都不能单独证明交付质量；运行中的快照可能变化，可刷新后重新查看。

Native、技能、定时及 Codex 排队任务开始前会核对接单时的会话项目和工作区；即使两个项目指向同一目录，改变项目归属也会使该任务失败，不会改用新位置执行。引擎绑定变化同样会阻止执行；请检查时间线中的失败原因并在正确范围重新提交。已接单的模型和验证命令仍使用原快照，当前权限收紧仍然生效。独立 Agent 的子工作区使用其专门的准备和权限校验链。

普通 Native 和直接团队任务接单时记录权限规则，工具调用同时遵守接单规则与当前规则中更严格的一方；之后放宽全局规则不会自动放宽已接单任务。无匹配规则的工具沿用原有默认行为，待审批的调用仍可由用户明确批准。普通 Native 恢复或继续带有此快照的旧运行时沿用原规则；更早没有快照的记录只能使用恢复时的规则。技能和定时任务沿用各自的固定权限策略，Codex 使用独立审批流程。已开始的外部操作不能因此撤回。

Native 工具在审批、Hook 或同文件写入锁等待后，实际分发前还会重新检查权限；规则改为拒绝或新增了未获得的审批要求时，该次调用不会启动。已开始的操作仍可能产生副作用。

取消 Native 运行时，不再启动其收尾 Hook；运行中的 Hook 会收到取消并等待受管进程清理。Hook 在停止前可能已有文件或外部副作用，需自行核对。

普通 Native 任务派生的子 Agent 继承父任务的权限规则；需要授权的子任务工具调用会在父会话请求审批，并标明子会话和工作副本目录。独立工作副本不限制宿主进程的文件或网络访问。

普通 Native 子任务的提问会显示在所属父会话并标明子 Agent。多个提问同时等待时，可从问题卡切换到其他待答问题；切换前重新核验服务、会话和请求，当前草稿在本页面保留。重连后仅恢复服务进程内仍有效的提问，回答路由回提出问题的子任务，不会自动回答。

Native 运行结束后的项目验证也检查 `project_validation` 和 `exec_command` 的接单及当前权限；拒绝时不启动命令，要求询问时等待用户决定。执行前重新核对会话、项目和工作区；拒绝或绑定变化会保留未验证结果。验证命令在宿主环境运行，目录本身不提供系统隔离。

终端和 Runner 启动遵守 `exec_command` 及各自入口的权限规则；需要询问时须选择会话并逐次批准，运行记录不可确认时不会启动。外部 Runner 的版本探测没有交互授权入口，规则要求询问或拒绝时不会启动探测，列表会显示不可用；如需使用，可先在权限设置中明确配置允许。已启动的进程不会因后续规则变更自动撤销。

聊天顶部的「当前任务」概览优先显示当前会话的活动运行，其次显示排队或最近运行；展开后可查看服务地址、已记录的执行目录、引擎/模型、授权或提问状态及预算快照。执行主机/容器或模型未记录时显示未知，不由服务地址推断。预算显示读取时已知值及未确认责任，并可手动刷新；断线或运行记录正在刷新时显示待刷新。选择「查看时间线与可用操作」进入原时间线，取消、恢复与审批仍遵循原有条件；提问在聊天卡片中回答。

浏览器发送排队任务前会保存本地重试凭据；响应不确定时保留正文，检查时间线后可重试同一请求而不重复接单。移除本地待确认记录不会取消服务端已接收的任务。浏览器存储不可用时无法提交此入口；重连可从服务端恢复已接收的任务。服务重启后的未完成任务依照现有中断和人工恢复规则处理，不会自动续跑。

Native 正在运行的任务可在时间线选择「向此 Native 任务补充」。补充会等待当前工具批次完成，在下一模型轮次边界加入上下文，不会中断工具；如果任务先结束、取消或进程重启，补充可能未被使用。时间线显示已接收、已加入上下文或未确认生效，加入上下文不保证模型已经接收或遵循。断线时可用同一凭据重试并查看状态；此功能与排队新任务不同。Codex 任务也可在时间线补充：服务将内容提交给当前轮次，接受不保证模型已经处理；发送结果不确定时不会自动重发，请先核对任务。同一请求凭据只查询既有记录。

Native 任务的大型工具输出可在时间线选择“查看已捕获输出”分页查看，Agent 也可按引用分页读取。保存内容仅是工具实际捕获的数据；命令的 stdout 与 stderr 各最多捕获 5 MiB，超出部分无法恢复。单条记录最多 12 MiB、单次运行和全库各最多 32 MiB，并为数据库备份保留空间；达到限制或存储失败时仅保留截断预览。输出可能包含敏感信息，保存在本地数据库并随所属运行删除；没有持久运行绑定的旧输出不由此功能恢复。

核对中断运行时，可将未确认生效的 Native 运行中补充显式加入恢复交接草稿，编辑后再确认恢复。先检查会话记录：补充可能已经进入上下文，系统不会自动重发或判断模型是否处理。交接最多 4000 字，过长时需手动摘录。

聊天中的“检查当前会话目录”按会话独立目录、项目根目录、服务进程默认目录的优先级检查目录是否可解析，并标明来源。未知或超时不等于目录故障；UNC 网络路径和无法确认执行边界的会话不会被此检查验证，映射驱动器是否远程也未判断。该检查不执行命令，不验证写权限、模型连接或远程环境，也不是操作系统沙盒。

项目或会话目录设置改变、连接变化后，需要重新检查；检查期间会核对服务身份。运行中的受管文件工具和进程入口还会检查绑定目录的设备及文件身份，若目录被替换则拒绝后续操作。目录检查是当时快照，不能证明后续不会变化；已启动进程及检查到实际访问之间的外部竞争不受该检查控制。

时间线的“工具输出存储与清理”显示全库及当前会话的逻辑用量。可在当前会话逐条清理已终结任务的捕获输出，清理后不能再读取，但任务、摘要和原文件保留；系统不会自动清理。SQLite 文件不一定立即缩小，旧备份及介质可能仍包含原始内容，清理不是安全擦除。

## 10. 自动化

| 功能 | 入口 | 说明 |
|------|------|------|
| 定时任务 | 设置 → 定时任务 | cron 表达式驱动，到点自动开任务执行提示词 |
| 工作流 | 设置 → 工作流 | 串联多步骤的固定流程 |
| Webhook | 设置 → Webhook | 事件发生时回调外部 URL |

定时运行请求授权或输入时，通知中心会记录提醒。点击“查看并处理请求”会先核对对应运行及请求仍然有效，再打开会话；已回答、超时、取消或服务重启后的旧请求不能由通知恢复。通知不会自动授权。

定时计划可复制到新建草稿，核对并修改后再创建；复制不运行任务，且新计划默认停用。创建时服务重新捕获项目和权限配置，不复制原计划的权限快照或运行历史；需要时可勾选创建后启用。提交前浏览器将请求键及原始表单（包括提示词）保存在当前标签页的 sessionStorage，刷新或断线后可使用原请求核对或安全重试；若原请求未接收，重试会创建计划。关闭标签页或清除浏览器存储可能丢失请求，届时须先核对列表。放弃未确认请求后用新请求创建，可能产生另一个计划；应先核对。返回结果是原计划的当前状态，可能已被修改或删除。这只保障创建记录的幂等，不保证任务外部操作幂等。

每次定时运行完成或未完成时，应用通知中心会保存一条本地通知，可从通知打开定时任务历史；具体状态和成果以历史为准。通知不是系统推送，服务停止期间不会执行任务，等待授权时仍需用户打开会话处理。

定时任务行显示当前发生的持久运行状态；出现“等待授权”时，可打开对应会话处理。历史记录会随运行事件和重连刷新，断线时标记状态待刷新。任务使用本地 Native 调度，服务停止期间不会执行；等待授权并不等于已获得授权。

计划行显示持久到期游标及计划时区，必要时可用“刷新计划状态”重新读取。游标是待处理的最早到期时间，并非保证开始时间；停用或配置受阻时保存的游标不代表会执行。已有运行未结束时不会重叠。新建或编辑计划时可选择服务重启后合并补跑（默认）或跳过未接单的到期周期；跳过只适用于启动时没有当前发生的已启用、绑定就绪计划，且不生成历史记录。已有发生仍按原恢复和核对流程处理；服务运行中因任务占用错过的周期仍合并补跑。历史中的最早到期和合并检查截止时间说明接单时覆盖的时间边界，不代表每个周期都单独执行。最近发生状态结算时间也不表示业务结果已经验证。

展开定时任务历史后，可对已接单的发生记录选择“查看本次运行结果与成果”。详情核对发生记录和运行的会话、项目、目录及 Native 绑定，显示读取时状态和已保存的文本回执；关联的 DOCX、PDF、XLSX 可查看已有有界预览并下载原件。历史缺少绑定、尚未接单、没有回执或没有关联成果时会分别提示；旧的未关联文件不会归到该任务。附件内容仍需业务核对，详情不是远程执行或无人值守运行的证明。

有已保存文本结果的终态运行可勾选其结果摘录并准备后续定时计划草稿。界面仅复制前 2000 个字符并标注来源与截断，可能包含敏感信息；确认前会提示已有草稿可能被替换。草稿默认停用且可编辑，不自动创建或触发；请核对任务目标、项目、时间、模型、预算与权限。新建计划使用创建时的配置，不继承旧运行的权限快照。此入口尚未运行验证。

远端主机的 Linux 用户服务管理可按固定时间范围及最近条数主动读取日志，并经确认下载屏幕上的摘录到浏览器。相对时间按远端机器时钟计算；最多返回所选条目中的前 16 KiB，截断时可能遗漏最新条目。下载包含主机及查询信息，控制字符已过滤但凭据未脱敏，应谨慎保管；不会自动采集或上传。此入口尚未运行验证。

新建或编辑定时计划时，可点击“预览未来到期时间”，由当前服务按输入的 Cron 和时区计算最多五个未来时刻，显示计划时区及 UTC。预览不会保存或运行计划；计划停用、服务停机、错过周期、授权及预算等可能改变实际执行。夏令时切换请核对显示的 UTC 时刻；Mock 模式不能计算。此入口尚未运行验证。

定时运行详情可选择“在交付物工作区查看此任务”，系统重新核对服务、项目、原会话、运行、目录及计划发生记录，再按原有草稿和范围切换保护打开对应任务的关联附件与文本成果；即使不在近期运行列表也可读取。可使用已有预览、下载和报告交接；关联不证明文件由本次运行生成。此操作不触发计划、不自动运行，也不改变预算或授权。

运行详情列出读取时仍待处理的授权请求和问题，可选择具体请求进入原会话。打开前后会重新核对服务、运行绑定及请求是否仍有效；授权仍由现有弹窗逐次决定，问题仍在聊天卡片中回答。请求超时、被处理或连接变化时请重新读取；此入口不会自动授权或回答。

定时运行详情中的“打开原会话时间线”会先重新核对服务、运行、发生记录和会话归属，再切换到原会话并打开时间线；这不会自动恢复或重放运行。时间线按运行 ID 单独读取并显示目标运行及步骤，包括不在近期列表中的运行；可刷新快照或返回近期时间线。目标视图可读取验证记录和预算暂停账本，并对符合条件的运行进入原有受控恢复流程；范围变化时需重新选择，连接变化后需重新读取并核对服务身份。

已终结的定时运行可在详情中准备后续任务草稿，将运行状态、已保存回执与验证记录带入同项目的当前会话；可另选已登记文本成果或一页捕获工具输出，核对后追加。准备和追加时重新检查服务、项目、来源会话、定时发生及运行绑定，草稿标明来源并区分记录与业务验收。文本和文件仍需人工核对；后续任务不会自动发送，也不继承定时运行的权限或预算，须按当前会话配置和授权处理。

已接单且仍在进行的定时运行可在详情中请求停止。服务会重新核对发生记录、服务和固定运行上下文；请求被接受不代表停止已完成，请刷新查看最终状态并核对已产生的影响。此操作不关闭未来计划；停用计划也不会自动停止当前运行。取消后的计划按原有核对流程处理，响应不明时先刷新核对。

对计划当前正在进行的运行，也可选择“停用计划并请求停止本次运行”。确认后先按服务、计划版本和当前发生核对并停用未来计划，再请求停止该运行；两步并非原子操作，停用成功后停止也可能失败或结果不明。请刷新两处状态并检查已发生的影响；停止请求不会撤销已产生的副作用。

## 13. MCP 服务器与插件

- **MCP 服务器**（设置 → MCP 服务器）：接入外部 Model Context Protocol 服务器，扩展 Agent 可用的工具集。
- 展开服务器后，可选择允许 Agent 列出和读取该服务器的 MCP 资源；默认关闭，调用还需权限规则或交互批准。仅可读取服务器当前列表中的精确 URI，文本会截断，二进制内容不会送入模型。资源内容来自外部服务器，应视为不可信材料。
- 启用资源后，可在展开的服务器面板中列出资源并查看文本；选择「重新核对并加入草稿」会再次读取，内容相同时追加到当前项目会话草稿，需自行审阅和发送。此入口不提供交互审批：资源或网络规则为询问、拒绝，或两者均无允许规则时不能读取。最多加入 5000 字，二进制省略，内容可能由服务器截断或变化；草稿按聊天设置保存在浏览器中。
- 启用资源后，可另行启用资源模板；仅支持服务器声明的固定来源、单路径段变量模板，变量限字母、数字、下划线和连字符，资源及网络权限规则仍适用。其他模板语法暂不支持。
- 同处可单独启用 MCP 提示模板：Agent 可列出模板及参数，按名称和参数获取内容；权限检查与资源相同。模板作为不可信参考数据返回，不会自动作为对话指令执行；文本和列表可能截断，二进制内容会省略。
- MCP 工具关闭后不能在设置里的工具调用器或 Agent 中继续发起调用；服务器重连或工具发生替换时需重新读取。已发给外部服务器的调用可能已产生效果。MCP 服务器运行外部代码，不是操作系统沙箱。
- 启用提示模板后，可在服务器设置中列出模板、填写声明的参数并查看返回内容；追加到聊天草稿前会重新获取并比较结果。模板与角色标签只是外部参考资料，需审阅后手动发送；最多加入 5000 字，非文本省略。此入口不支持交互审批，提示模板或网络规则为询问、拒绝，或均无允许时不能调用。服务器读取可能有外部副作用，结果和参数可能包含敏感信息。
- 断开 MCP 时会请求取消正在进行的调用并关闭连接；若调用或受管进程未能在期限内确认结束，操作会报清理未确认，服务保留连接记录供后续核对。已执行的远端操作不会撤销，脱离受管进程树的进程不保证被终止。
- **插件**（设置 → 插件）：启用/禁用内置功能模块。
- 插件启停会更新该服务内后续的插件 Hook，包括已打开会话中的后续事件；已启动的 Hook 进程可能继续运行。启停覆盖仅保存在当前服务进程，重载或重启后以插件清单为准；Hook 运行外部代码，不是操作系统沙箱。

交付物入口打开统一工作区，可在文本成果、附件与报告、办公表格、研究来源和当前会话成果之间切换；各类记录仍使用原有存储与权限。相同服务、项目和会话内切换类型会保留面板中尚未提交的草稿，关闭工作区或切换范围会清除这些页面草稿。连接中断时暂停操作并清除旧的已载入结果，重连后重新核对服务身份；服务身份变化会重置工作区。

在项目任务状态中查看运行结果时，可选择“在交付物工作区查看此任务”。系统先核对服务、项目、会话和运行并按现有范围切换保护进入所属会话；交付物工作区按运行 ID 重新读取任务，包括近期列表以外的历史运行。可查看明确关联的附件预览及原件、读取登记关联的文本成果并下载，也可按原流程交接报告；这些关联不证明文件由该运行生成。手工或未关联的项目附件和办公成果仍在各自类型中查找。

「当前会话成果」可按关联附件或登记文本成果切换显示，并按运行记录中的附件名称/ID、已加载文本成果的路径/ID 查找；筛选不搜索文件内容或尚未加载的文本页。展开文本成果并读取后可继续加载后续页，结果仅限当前项目、会话和运行的登记关联。筛选保留已选预览与登记草稿；不匹配不代表其他任务或未加载页没有成果。

在「当前会话成果」中打开任务关联附件后，可交接到「附件与报告」。点击“核对并打开任务附件”会按当前项目、会话、服务和附件 SHA-256 重新核对并打开，即使该附件不在当前列表页也可继续查看或按支持范围用于报告。交接只在当前页面和相同服务、项目、会话范围内保留，可放弃；不会自动修改原件或报告草稿。任务关联不证明该任务生成了文件，内容仍未核验。

在交付物工作区的「文本成果」中选中项目成果后，可直接交接到报告，无须关联任务。报告侧准备并确认时会重新读取快照、核对服务、项目、会话及成果身份，并附上路径、版本、ID 和 SHA-256；读取期间报告草稿发生变化则不追加。文本按行追加，空行省略，Markdown 和 CSV 作为纯文本处理；内容和来源需核对，原文件及已登记快照不修改。每次只能有一个待复用成果，暂存于当前页面内，可放弃。

办公表格中选择已登记的纯数据 XLSX 成果，可准备继续编辑：读取受支持的完整工作表并预览前 10 行，确认时再次核对来源与草稿，然后替换表格草稿并设定同名输出。单元格初始作为文本，数字或布尔列需重新选择类型；编辑后仍须转换为表格输入并生成。输出是新附件版本，不修改原件；样式、公式、图表和打印设置不会恢复，业务数据未核验。含图表成果不提供该快捷入口。

表格草稿的分组汇总可选择一个首要分组列及最多 18 个其他分组列，按组合统计行数或对数字列求和。各列按所选类型比较，空值单独参与分组，结果按组合首次出现的顺序排列；求和忽略空值，全空时结果为空。汇总是静态数据，会替换当前编辑草稿但可撤销；可转换为表格输入再生成独立 XLSX，原文件不变。数字或布尔值不符合类型、结果超出安全精度或限制时拒绝；业务口径和结果需人工核对。

表格草稿的“组合条件筛选”支持 2–5 个条件，按全部满足或任一满足保留行，可组合文本精确匹配、包含、空/非空及闭区间数值筛选。文本区分大小写且不自动清理空白；数值条件中的空单元格不匹配，所有数值条件的整列都按安全精度规则检查，任一无效即不应用。可预览匹配行数及前 5 行，应用后可撤销、转换并生成新 XLSX，原文件不变。筛选是静态操作，不随数据变化自动更新；处理说明需用户填写，业务结果未自动核验。

表格编辑器可选择本地 UTF-8 CSV 作为右表，分别选择当前表及右表的 1–3 对匹配字段，勾选右表列，预览匹配数、未匹配数和前 5 行后追加到草稿。各字段均按原始文本精确匹配，区分大小写、保留空白，不转换键类型；任一键为空的行不匹配，右表完整非空键组合重复则整次拒绝，当前表重复组合可匹配同一右表行。保留当前表全部行，未匹配的追加列为空，右表多余行忽略；追加列默认文本，不执行公式。右表上限 1 MiB、1000 行、20 列；结果仍受 20 列及 5000 格限制。结果为可撤销静态草稿，转换后可生成独立 XLSX，原文件不修改。右表仅在本地读取，界面显示 SHA-256；如需随成果交付处理口径，应将文件身份及匹配规则写入用户填写的处理说明，业务正确性需核对。

生成办公成果时可填写输入来源、变换口径和限制或待核对事项。说明随该成果回执登记，可在成果详情查看或下载校验报告；也保存在手动导出的表格草稿中。说明不写入 XLSX，发送文件时请同时交付校验报告；它是用户填写的声明，不会自动记录编辑、核实来源或验证业务数据。修改数据后请同步更新说明；说明可能包含敏感信息。

在办公成果详情可下载“XLSX 与回执交付包”。浏览器先重新核对当前服务、项目、会话、成果和回执，校验 XLSX 原始字节的大小及 SHA-256，再将工作簿、带成果及附件身份的回执 JSON、说明文件打包为 ZIP；打包期间归属或所选成果变化会停止下载。ZIP 内固定文件名，原件不修改。回执并非数字签名，不能证明业务内容或版式正确；用户填写的说明和处理参数可能包含敏感信息，分享前请检查。

办公表格可从项目已登记 CSV 附件直接继续处理：按名称查找并分页加载，选择后读取完整原件，预览表头、前 5 行和附件 ID/版本/SHA-256；确认时再次读取并核对来源与草稿，才替换 CSV 和表格编辑草稿。支持 UTF-8、最多 1 MiB、1000 数据行、20 列及 5000 格；默认列类型为文本，不执行公式。原附件不修改；已有结构化输入、文件名、运行关联、汇总配置和用户填写的处理说明不自动改变，请编辑后重新转换并更新说明，再生成独立成果。

项目 XLSX 导入可按名称搜索并分页定位附件，再选择可见工作表，读取受支持的完整范围后勾选列和连续数据行，预览后载入表格草稿；表头始终保留，数据行从 1 开始计数（不含表头）。解析仍需整张工作表符合 A1:T1001、5000 格及 2 MiB 限制；默认拒绝公式。可明确选择仅导入公式的已存储缓存：系统标示公式单元格坐标并要求确认，任何缺失或空缓存、错误、共享或数组公式会使整张工作表拒绝；即使所选范围未包含该单元格也一样。缓存可能过期或错误，系统不计算、重算或验证公式。隐藏行列、合并单元格、图表、筛选和错误值等仍不支持。日期转为 ISO 文本，百分比和货币使用底层数值；样式、货币符号和版式不保留。载入不会修改原件，默认列类型为文本；涉及缓存时可将提示追加到用户填写的处理说明，核对后转换并生成新成果。该缓存导入功能尚未运行测试、构建或实机验证。

CSV 或表格草稿导入、编辑、撤销或调整列类型后，当前结构化 JSON 会标记为待确认，生成按钮暂停。可选择“转换为表格输入”，替换非空 JSON 前会先确认；也可明确选择使用现有 JSON，不转换表格。转换确认期间草稿或归属变化会取消替换。待处理的 CSV 文件需先应用或放弃，才能生成。手工 JSON 仍可独立编辑和生成。表格草稿导出包含输入状态；从文件恢复含 CSV/表格的旧版或新版草稿后，需重新转换或确认使用 JSON，避免误用旧输入。生成前仍应核对汇总配置及处理说明。

在附件详情选择已登记的 PDF 或 DOCX，可填写资料来源及访问时间、成稿处理口径、限制与待核对事项，下载报告交付包。ZIP 包含原始报告、附件身份与用户填写说明的 JSON，以及说明文件；浏览器在打包前后核对服务、项目、会话与附件，并校验原始字节大小和 SHA-256。交付说明还可单独导出本地草稿，在同一服务、项目、会话及附件 ID 和 SHA-256 下恢复、修改并再次打包；恢复需确认替换当前说明，不会自动保存到项目。说明由用户填写，不会自动提取或核验来源、事实、OCR 或版式；附件哈希并非数字签名。原附件不变，分享前请检查敏感信息。

将表格交接报告时，可选择当前表格的列和连续数据行（每次最多 99 行，另含表头），填写来源与处理口径。交接说明会记录当前草稿中的行范围和列序号；这些序号不表示原始文件的位置。报告中选择结构化章节后才追加，支持分次加入多个表格或范围。源文件不修改，单元格按文本复制，不计算公式；数据和来源仍需核对。PDF 报告还受 10 列及 1000 格的每表限制。

「当前会话成果」默认列出最近运行中明确记录且与当前会话、项目、服务匹配的工具返回附件；历史未关联、手工生成或未记录关联的文件仍可在项目附件等类型中查看。关联只说明工具返回该附件，可能复用旧成果，并不证明事实、版式或业务质量。

「项目与任务 → 任务状态与结果」按当前项目的持久运行记录显示等待处理、运行与排队、最近结果，每组最多 25 条；这不是会话数量或全部历史。列表显示运行和所属会话，可读取已保存的有界结果或打开所属会话；打开会话前会重新确认项目和服务归属。等待状态只反映记录，不保证审批或问题仍有效；活动运行若当前服务没有对应执行者会标记待核对，断线后清除列表并等待刷新。已归档会话、旧的未绑定项目记录、内部子任务和手动来源读取记录不在此摘要，可通过原有入口查看。

项目任务中心的查找支持组合关键词与状态范围：全部、等待处理、运行与排队、失败/取消/中断、执行结束。空关键词可浏览该状态，翻页继续使用已提交的条件；选中结果可查看详情或打开所属会话。等待处理和失败范围都包含中断；等待状态不保证请求仍有效。搜索按实时记录分页，不是固定快照；运行记录变化后当前页标记为旧快照，可刷新该页，打开结果会重新核对。主机边界可能使某页较少或为空；旧服务若不支持状态筛选会报错，需要更新服务。

任务中心在当前页面内按服务地址、服务身份和项目记住分组、搜索输入、已提交的筛选页及所选运行。切换到聊天、交付物或自动化后返回，会重新核对服务并重新读取对应页和运行；读取失败或归属变化时会提示重新查找，不使用旧快照。可选择“忘记任务工作上下文”；刷新或关闭页面会清除记忆，搜索词可能含敏感信息。恢复只是读取记录，不自动恢复运行或处理授权。

项目任务结果会列出读取时可确认的待授权请求和待答问题。选择具体请求后，系统在切换前后核对服务、运行、项目、会话和请求有效性，再打开原会话的授权弹窗或问题卡片；请求过期或已处理时需刷新。查看不会自动授权、回答或恢复运行，保密问题未处理时会阻止可能丢失其输入的切换。

在项目任务状态中选择“查看结果”，可在同一处核对已保存的验证命令、退出码和输出，以及任务前后文件采样的新增、修改、删除路径；路径可筛选。采样未启用、尚未保存、不可用或记录不完整时不会显示为零变化。采样只覆盖有界范围，不保存文件差异，也可能包含同期的其他修改；验证记录不等于业务验收，模型文本不是验证证据。页面不会修改或合并文件。

运行结果中的“准备交付摘要”可将已保存的运行文本、验证记录和文件采样整理为可编辑的文本草稿，再由用户核对并下载。下载前重新核对服务、项目、来源会话和记录；来源发生变化时保留编辑，需复制后重新准备。摘要标明文本与验证证据的区别、采样局限及截断；不会读取项目文件全文或自动发送。草稿只在当前页面内按服务、项目、当前会话和来源运行保留，刷新或关闭页面会丢失，未放弃的草稿会触发浏览器离开提醒；下载文件可能含敏感信息，请检查并妥善保管。

主内容区顶部的工作台导航始终显示「项目与任务」「当前工作」「交付物」「自动化」四个区域，以及当前位置、当前项目、会话和服务地址。切换区域会返回该区域在本页面最近打开的页面；首次进入分别打开任务状态、当前会话、文本成果和定时任务。该导航不切换项目或会话；会话与项目不一致或会话信息尚未确认时会提示。离开自动化或设置时仍按原规则确认未保存编辑，断线与刷新时的草稿限制不变。定时任务使用自身配置的项目，工作流与 Webhook 属于当前服务。

侧栏日常导航分为「项目与任务」「当前工作」「交付物」「自动化」四组，可展开相应二级入口。项目及任务列表始终位于导航下方；交付物可直接进入文本成果、附件与报告、办公表格和研究来源，自动化可进入定时任务、工作流和 Webhook。窄屏通过顶部菜单打开侧栏，选择入口后收起；可用 Tab 操作分组和入口，Escape 关闭侧栏。设置和手机连接仍保留原入口。

## 14. 数据：导出、导入、备份

「设置 → 数据」三个动作，语义不同：

| 动作 | 格式 | 何时用 |
|------|------|--------|
| 导出数据 | 单个 JSON 文档（含 schema 版本，覆盖全部业务表） | 跨版本迁移、换机器 |
| 从 JSON 导入 | 替换式：文件中每张表在单事务内覆盖当前内容（要么全成，要么全不做） | 恢复导出文件 |
| 立即备份 | SQLite 文件级热快照（带 UTC 时间戳，Agent 不停机） | 同版本灾备 |

备份时可填写当前服务所在机器的已有绝对目录路径；留空使用默认备份目录。自定义目录不会自动创建，写入受服务进程的文件权限约束；备份使用独立文件名，不覆盖已有文件。完成后界面显示实际文件路径和大小；备份文件可能包含私人数据，应妥善保管。

“查看已有备份”按当前填写的目录列出最近修改的最多 100 个符合命名规则的普通 SQLite 备份文件，显示路径、大小和修改时间；留空查看默认目录。清单不会读取文件或检查完整性，也不包含附件、成果原件等独立文件，不会自动删除任何文件。

可将“立即备份”生成的独立 SQLite 快照复制为一个全新数据目录中的 `data.db`，供后续人工恢复。先停止接单并核对所有相关服务和任务，再在已安装依赖的 `agent` 目录执行：

```bash
uv run python -m minimax_code.snapshot_restore --snapshot /absolute/backups/minimax-code-backup-example.db --new-data-dir /absolute/new-data
```

Windows 也可双击程序目录中的 `Restore-Snapshot.cmd`，按窗口提示输入快照和新数据目录的绝对路径，核对后输入 `YES` 才开始；取消不会启动恢复。它优先使用该版本 `agent/.venv/Scripts/python.exe`，缺失时要求输入已有 Python 3.11+ 的绝对路径，不安装运行时。旧发行包可能没有此入口；窗口会保留结果和退出码供查看。此交互入口尚未进行实机演练。

Windows 使用本机绝对路径。目标父目录须已存在，目标目录必须不存在；工具独占创建新目录，绝不覆盖已有数据。源和目标应位于可信本机文件系统，操作期间不得修改或替换文件；带 SQLite WAL、SHM 或 journal 旁文件的源会被拒绝。工具以临时文件写入并同步后，通过硬链接独占创建 `data.db`，因此目标文件系统须支持硬链接。失败或中断可能保留目录和 `.RESTORE-INCOMPLETE`，不要启动它；已安装版本的 `start-release.mjs` 会拒绝该标记，其他入口不保证识别它。成功时输出字节数与复制流的 SHA-256，不验证来源、数据库完整性或版本兼容性，也不自动启动或迁移。断电时目录项持久性依赖文件系统；确认实际内容后再操作。

**这只恢复数据库快照**，不恢复文本成果、附件、检查点文件、工作区、系统密钥环、环境变量或其他外部文件。预算、定时任务、Webhook 和执行责任等记录回到快照时点，启动前须核对快照后发生的外部操作及未结责任，避免重复执行；并分别保全或恢复缺失文件和凭据。使用与快照兼容的版本，先保留原数据和备份；此流程尚未进行真实恢复演练，不保证恢复成功或业务可用。

可将已完成的独立 SQLite 快照或 14.1 节手动创建的数据包复制到另一个已有目录。在已安装依赖的 `agent` 目录执行（Windows 使用该机器的绝对路径）：

```bash
uv run python -m minimax_code.backup_copy --source /absolute/backups/data-vault.zip --destination-parent /absolute/other-backups
```

Windows 可双击程序目录中的 `Copy-Backup.cmd`，输入已完成的备份文件与已有目标父目录的绝对路径，核对后输入 `YES` 才复制；取消不会开始复制。它优先使用该版本 `agent/.venv/Scripts/python.exe`，缺失时要求输入已有 Python 3.11+ 的绝对路径，不安装运行时。窗口会保留结果和退出码供查看；旧发行包可能没有此入口，交互入口尚未进行实机演练。

工具在目标目录下新建随机子目录，复制文件并写入含字节数和 SHA-256 的 `receipt.json`，不覆盖原文件或已有备份。成功标记为 `.COPY-COMPLETE` 且不存在 `.COPY-INCOMPLETE`；失败或中断可能同时留下两个标记，应视为未完成并保留目录供检查，不要将其当作备份。复制期间不要修改或替换源文件，也不要在目标目录中并发操作；带 SQLite WAL、SHM 或 journal 旁文件的数据库会被拒绝，不应复制运行中的数据库。摘要只记录复制流，不认证来源或证明文件完整、可恢复或与当前版本兼容。此操作仅复制指定文件，SQLite 快照不包含独立 vault，数据包的排除范围见 14.1；两者都不能替代另行保全凭据、工作区和其他外部文件。备份及收据可能包含敏感信息，目标目录权限由操作者管理。

导入前会弹出确认（显示行数与 schema 版本）。**大规模导入前请至少保留一份备份**；旧版本会拒绝导入新 schema 的文件，而不是损坏自身。

文本成果的 JSON 导出只包含登记元数据，不包含文件内容；「立即备份」也只生成数据库
快照。保留或恢复文本成果时，须同时保存匹配的数据库与 Agent 数据目录中的
`text-artifact-vault` 文件夹。只导入 JSON 或只恢复 SQLite 文件不会补回缺失的原始
版本字节。

项目附件原件同样单独保存在 `attachment-vault`，JSON/SQLite-only 恢复也不能补回它们。

# 子任务工作区审阅与收集

打开当前会话的子 Agent 面板后，最近 100 个有持久父任务绑定的直接子任务会在刷新或重连时恢复。服务无法确认仍在运行的未终结记录会显示“状态待核对”，包括可能由父任务同步等待的子任务；旧的无绑定记录及更深层子任务不在此列表中。 在所属项目会话中可读取持久子任务并选择最多 5 个已结束记录，填写后续目标后一起追加至聊天草稿。每项附带状态、部分结果标记、任务要求、结果和错误摘录；服务端截断及草稿截断会标明。追加前重新读取并核对所选记录和服务、项目、会话归属。文本不是验证或收集回执；文件与验证证据仍需分别审阅。此操作不发送、不合并，也不执行验证；结果可能含敏感信息，分享前请检查。此功能尚未运行验证。

已知运行 ID 时，可在子 Agent 面板按 ID 查询较早的直接子任务及保存的结果摘录，不受最近 100 条限制。仅显示能确认属于当前会话和项目的记录；活动但无法确认仍在运行时显示待核对，不自动重跑。

也可在「浏览子任务历史」中按创建时间倒序读取并加载更多，每页 50 条，展开查看状态和结果摘录。翻页绑定当前服务、项目及会话，切换或断线需重新读取；历史不是固定快照，新建或删除可能影响后续页面。仅列出具有可确认父运行关联的直接子任务。

历史中已结束且服务未发现仍在运行的子任务，可编辑结果交接并加入父会话草稿；加入前按 ID 重新读取并核对记录和服务、项目、会话。摘录可能截断或包含敏感信息，需审阅后手动发送；文本不代表文件已合并或验证通过。

在子 Agent 面板展开已完成的内部子任务，选择“查看子任务工作区结果”，可查看当前父目录与子任务结果的文件差异；这不能证明同期变化由 Agent 造成。确认后选择“收集已审阅的无冲突变化”。存在父目录冲突或子任务删除时必须手动处理；收集期间出错可能部分写入，应重新查看和核对。差异过大、非 UTF-8 或超出显示预算时需手动查看原文件。 审阅中可选择最多 5 个冲突，填写意见后将父子差异摘录追加至当前会话草稿；追加前会重新读取并核对审阅版本与所选文件。每项最多 4000 字符、总计最多 12000 字符，截断或不可用会标明；内容可能含敏感信息，请先检查。此操作不写入、发送或验证，后续任务须重新核对当前文件并保留用户修改。该功能尚未运行验证。子任务工作区及备份保留。仅支持可核实持久父运行绑定的直接子任务；旧记录、嵌套或受限执行子任务不能从此入口收集。普通独立工作目录不是操作系统沙盒。

对符合条件的文本冲突，可展开手动合并编辑器，并查看经摘要核对的完整子任务文件作为只读参考；完整文本受总显示预算限制，未显示时请在子工作区查看。编辑器从当前父文件开始，写入前仍需明确确认，系统保留原文件备份。

办公成果可从当前项目已登记的 XLSX 选择可见工作表和列，读取完整有界数据后载入表格草稿，再选类型、清洗并生成新表或静态汇总/图表。原附件不修改。导入限 2 MiB、A1:T1001、5000 格；公式、隐藏行列、合并单元格、图表、筛选及不明确格式等会拒绝。日期转 ISO 文本，百分比和货币保留底层数值，样式不保留；这不是完整 Excel 编辑。替换已有草稿需要确认，下方已转换输入不自动覆盖。


在设置的远程主机列表中可编辑已登记主机的名称、地址、用户名、SSH 端口、私钥路径和远端服务端口。连接参数变更会断开此主机已有隧道；若当时正在连接或已连接，保存前会提示，之后需重新连接。远端会话和文件仍由远端服务保存，此操作不搬迁数据，也不代表远程生产环境已验收。

文件传输区可通过独立 SSH 只读浏览远端 Linux 目录并选择普通文件，选择后仅填入远端路径，仍需确认上传或下载。此功能需要远端 Python 3；每次最多读取 200 项，不列出符号链接和特殊文件，目录内容可能在传输前变化。

设置 → 远程主机的“主机运行快照”可手动读取指定主机的运行时间、根分区磁盘、内存及 CPU 占用最高的进程名称和 PID，不显示进程命令行。每次点击通过独立 SSH 执行固定只读命令，不依赖服务隧道，也不自动刷新；结果仅保留在当前页面。该功能需要远端 Linux 提供 uptime、df、free、ps 和 head。超时、缺少命令或 SSH 失败会显示失败或不完整结果，不能据此推断主机离线，也不能证明任何任务仍在运行。进程名称和诊断输出可能含敏感信息。

设置 → 远程主机的“上传 / 下载文件”可对登记主机显式传输单个文件。填写当前服务主机上的本机绝对文件路径和远端 Linux 绝对文件路径；浏览器文件选择不会将文件自动送到服务。上传会暂存、比对 SHA-256、检查目标未变化后发布，并在替换远端已有文件时保留备份；下载校验后仅创建新文件，本机目标已存在时需选择新路径。确认框展示主机与路径，只有确认后才传输。上传编号和远端路径保存在当前标签页的会话存储，可复制后查询；本机路径不保存在该记录中。若响应中断先查询状态，未确认终态前不会从此入口发起下一次上传。手动输入编号也可查询，关闭标签页前请自行记录。校验不证明文件业务内容正确；没有自动同步或自动重试。

上传后可复制恢复记录并自行保存；记录含当前服务地址、登记的主机 ID、SSH 地址、用户名、端口、远端路径和传输编号，不含私钥路径或本机文件路径，但仍可能含敏感的主机和路径信息。以后可在同一服务和匹配的主机下粘贴记录，点击“填入查询信息”后核对，再手动查询上传状态。填入不发起远程操作，也不覆盖当前标签页的未决上传记录；记录本身不证明主机密钥或上传结果。剪贴板不可用时可手动选择复制。

远程主机面板会定期读取隧道状态。SSH 进程仍在但远端服务连续两次未通过健康检查时显示“服务不可用”并隐藏旧链接；随后探测成功会恢复链接。SSH 进程退出时仍按原有有限次数尝试重连，失败后可手动连接。本地服务断线或状态无法读取时显示“状态待核对”，不沿用上次链接；本地服务重连后刷新状态。上述状态只表示连接与服务健康检查，不判断远端任务是否继续运行，也不启动远端服务。

连接后选择“打开远端独立标签页”。远端页面顶部显示当前服务地址，并可打开来源页面；各服务有自己的项目和会话，不同步文件或迁移运行。该入口需要远端服务提供更新后的前端，并以隧道页面自身的回环地址连接服务，不使用构建时设置的其他服务地址。返回地址仅记录不含凭据的来源页面地址；如果来源页面不是 HTTP 回环地址或本身是隧道页面，返回入口不会显示，原标签页仍可使用。断线后回到来源页面，在远程主机设置中刷新状态并按需重新连接；隧道端口变化后应重新打开远端页面。

聊天输入区显示提交服务、会话及其所属项目，并显示已知会话工作区或项目目录；项目目录不保证就是实际执行目录，运行详情记录实际位置。解析 `@repo` 或 `#file` 时若服务连接、会话、项目或草稿发生变化，会停止提交并保留草稿，请核对位置后重新发送。顶部项目选择影响新会话的归属，不会把现有会话移到所选项目。

### 自动化工作区

侧栏的“定时任务”“工作流”和“Webhook”进入同一个自动化工作区，可在标签间切换并保留当前表单草稿；离开或切换服务会丢失未保存编辑。未确认的定时创建请求另按前述规则保存在当前标签页。定时任务按各自配置绑定项目和执行上下文，工作流及 Webhook 属于当前服务。断线后操作暂不可用，重新确认服务后查看实际记录；断线前提交的结果可能未知，应先核对再重试。服务身份来自数据存储，克隆的数据可能保留相同身份。任务仍可能等待用户授权或输入，这个入口不保证无人值守或远程运行。

### 设置导航

设置优先显示模型、Provider、远程主机、权限及数据与诊断；其他功能可通过“展开进阶设置”访问，原有设置直达入口仍然可用。设置页显示当前服务地址及数据身份；模型、凭据和权限按当前服务管理，项目相关设置以对应页面为准。切换设置标签保留已打开的表单，离开时如有编辑会提示；切换服务将清除旧服务未保存的表单，断线后先重新确认服务。数据身份随数据库保存，克隆的数据可能具有相同身份。

### 查找交付物

交付物、自动化和设置页有过编辑时，关闭或刷新浏览器会由浏览器提示可能存在未保存内容。编辑提示是保守判断，不代表服务端任务尚未提交，也不取消已接收任务。服务断线和服务身份变化不能由页面阻止；切换服务时旧服务的表单不会带到新服务。

已结束运行的时间线以及当前会话关联成果提供“准备后续任务草稿”。先查看实际保存的运行状态、验证记录及可与当前项目附件核对的关联；确认后才追加到当前会话已有草稿，不自动发送。追加前再次核对服务、项目、会话和记录，内容变化则要求重新准备。附件只列身份，原件未读取；历史缺失、结果未知、输出截断和未核验均不视为通过。 如验证记录保存了标准输出或标准错误，可先预览并勾选加入草稿；每个已保存输出流最多加入前 4000 字符，并标明保存或摘录时的截断，缺失的输出不会补造。追加前会再次读取并核对所选摘录，内容发生变化时需重新准备。输出可能含敏感信息，分享前请检查。该功能尚未运行验证。

子工作区收集后，审阅面板显示服务端回执中已复制、父目录原已相同和未处理冲突的文件。完整收集的回执可在刷新审阅后再次查看，并可主动追加到当前会话后续任务草稿；追加前重新核对服务、项目、会话与回执。回执不证明文件此刻未变化，也不是验证或验收结论。收集报错时可能已有部分文件写入，界面不会猜测清单，请重新查看并核对父目录。

运行时间线的已捕获工具输出支持按区分大小写的字面文本查找并继续查找下一处，每次只读取有界摘录。搜索只覆盖已保存的捕获内容，工具上游可能已截断；未找到不证明原始输出没有该文本。切换会话或连接时预览清除，不会将结果自动发送给 Agent。

聊天输入区的“下一任务 token 上限”可为新任务填写正整数；留空时不覆盖服务端默认，界面不推断默认值。该输入对当前会话后续新任务及其子任务生效，切换会话或连接变化后清空；排队任务在提交时固定预算，重试使用原请求快照。运行时间线的预算账本可展开共享家族请求明细，查看前 50 条请求的归属运行、状态、已知用量、预留估算和核定责任；家族合计包含共享预算的父子任务及恢复运行，旧记录可能缺少归属。每日预算是独立的服务配置。该限制按 token 计数，既不是货币金额，也不是 Coding Plan 的费用上限；Native 依据估算控制、Codex 对已观察用量事后控制，不能保证严格费用上限，未知用量不当作零。

排队编辑器提交前会保存服务身份及重试凭据；重试时服务身份不同则拒绝发送。旧的待确认记录若没有服务身份，只能先核对任务，再按需移除本地记录，不能直接重试；移除本地记录不会取消已经接收的任务。服务身份依赖当前数据存储，不能识别完整复制的数据目录。

设置 → 模型 → 每日 token 预算与账本可查看和设置当前服务的每日限额。账本日界线是 Asia/Shanghai 的 00:00；已知值、预留责任、未知请求和不完整基线分别显示。保存正整数覆盖环境默认，恢复环境默认时若未设置环境变量则无日限额。同一服务进程内新 Native/Codex 预算预留使用最新设置；已在途请求不撤回，Codex 活动 turn 在下一次用量通知按观测值处理。该设置不限制所有外部程序，不是金额、Coding Plan 费用上限或严格硬限额。设置文件 daily-budget-settings.json 位于服务数据目录，现有数据库备份/数据包不含此文件，迁移需单独备份与恢复；数据库账本仍按原流程备份。

每日 token 预算设置可在“设置 → 模型 → 每日 token 预算与账本”单独导出、导入。导出的 JSON 只包含界面保存的限额和来源服务身份，不含账本、密钥或环境变量；null 表示使用目标服务的环境默认，可能没有限额。导入先展示目标与覆盖内容并要求确认，服务端比较当前保存值以防并发覆盖；连接变化或设置变化时需重新读取。此功能不改变现有数据包格式，也不迁移账本或在途请求。

已有定时计划可编辑名称、目标、cron、项目、模型、模式、时区和 token 预算。编辑基于打开时的计划版本；其他位置修改后需先核对并选择是否载入最新版本，保存失败时草稿保留。保存会重新捕获当时的权限和项目配置，不会自动启用计划；已接单运行保持原快照，尚未接单的旧发生按替代规则关闭。需要核对的旧运行仍需明确核对，修改计划不解除该状态。定时运行仅支持本地 Native，不保证无人值守。

定时计划因失败、中断或预算暂停进入“需要核对”后，可在计划卡片查看当前发生的固定快照和本次运行结果；打开原会话可进一步核对步骤及文件。明确勾选并确认后，才可启用未来计划；此操作不会恢复或重放旧运行。若需继续旧运行，请在其会话使用原恢复入口并按要求核对。计划版本、发生或服务变化时请刷新重新核对；响应不明时先查看实际状态，勿重复执行。

在聊天头部选择与当前会话不同的可用引擎后，可使用“切换并交接”。系统读取当前服务内最近 12 条持久消息及最多 20 条运行，生成有界摘录供用户编辑目标、约束并检查敏感信息；这不是完整历史或自动验证的总结。确认后在同项目默认目录新建目标引擎会话，将审阅文本写入未发送草稿；原会话保留，引擎线程、工具状态、权限和预算不会迁移。来源为独立工作区或自定义目录时，项目必须配置明确根目录；界面显示两处目录并在创建时核对绑定。文件不会复制或合并，请自行核对目录与变更。原运行不会停止，读取期间内容变化需重新准备；创建响应不明时应先核对会话列表，避免重复创建。

运行中断后，在时间线选择“读取中断记录并核对”。界面显示读取时的持久步骤、结果未知的工具调用和工作区差异入口；记录缺失不代表没有副作用，先核对当前文件及外部系统。明确勾选后才可创建关联的新运行，系统不会自动重放工具步骤，也不保证从原执行位置继续。重启前预算暂停的运行需填写累计 token 上限。恢复请求的 ID 和参数保存在本机浏览器以便对不明结果使用相同请求重试；原记录、服务或会话变化时需先核对时间线。手动移除本地待确认记录不会取消已接收的运行。


聊天中也可要求对项目 CSV 或受支持的 XLSX 附件筛选后按类别汇总，生成新的静态表格，例如按类别统计记录数、金额合计与平均金额。空分类单独成组，金额全空时合计和平均值为空；原附件不修改。详细计算口径、限制和交付位置见 [办公成果说明](office-delivery.md#聊天中按类别汇总附件)。该分组功能尚未运行验证。

Native 项目会话的聊天输入区提供“附件成稿工作流”：填写成稿目标、读者与要求，读取项目附件列表并选择一份 TXT、CSV、PDF 或 DOCX，生成可编辑的聊天草稿。准备时核对项目、服务及附件身份；草稿可以继续修改，只有点击聊天的发送按钮才会发起任务，任务模式、预算和权限仍按现有运行流程生效。附件读取有格式与内容范围限制，扫描件不会自动 OCR；报告生成不等于事实或版式验收。该入口尚未运行验证。

“专题研究工作流”可填写研究问题与范围，选择当前项目保存的网页来源，并选择在任务指示中请求尝试联网，或请求仅使用已选来源。该选择只改变草稿文字，不设置或强制执行网络权限，网络访问仍受现有权限规则控制。准备时只读取已保存记录、核对服务和会话，不自动搜索或调用模型；草稿追加后仍需主动发送。联网搜索依赖已配置的搜索服务和权限，搜索摘要及保存的有界网页摘录都不等于事实核验；结果应标明实际来源并区分推断。该入口尚未运行验证。

同一输入区的“表格任务工作流”可选择已登记的 CSV 或 XLSX，填写单表处理目标；也可指定左右两份附件与各自键字段，准备精确左关联请求。XLSX 要填写准确的可见工作表名称。左关联保留左表顺序，空键不匹配，右侧完整键重复时拒绝；不会模糊匹配。CSV 限 UTF-8、1 MiB 和 1000 行，XLSX 限 2 MiB、A1:T1001、5000 格及 1 MiB 提取文本，公式和复杂结构不支持。准备会核对所选附件身份并追加到可编辑草稿；发送后由现有任务流程执行，原附件不修改，成果仍需业务核对。该入口尚未运行验证。

聊天中可让 Agent 对项目 CSV 或受支持的 XLSX 附件生成结果按最多三个字段升序或降序排序；空白排在各排序键的最后。排序发生在筛选和可选分组之后，原附件不修改。日期按文本排序，详细口径和限制见 [办公成果说明](office-delivery.md#聊天中排序附件结果)。该排序功能尚未运行验证，结果仍需业务核对。

办公表格成果可准备含实际存储单元格的后续草稿：先核对最多 1200 字的有界预览摘录，再追加到当前会话；追加前重新读取并核对身份和内容，不自动发送。预览范围、长表名、单元格或摘录可能截断，未展示区域不能推断为空；数字为存储原值，公式不执行、缓存可能过期，业务内容仍需核对。预览无单元格时可下载原件。


聊天中也可按多个字段联合汇总附件，例如按部门和月份统计金额；只有完整字段组合相同的记录才会合并。详见 [多字段联合汇总](office-delivery.md#聊天中按多个字段联合汇总)。此能力尚未运行验证。
